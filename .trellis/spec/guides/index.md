# 思考指南

正文读取与换会话接续遵循[有界读取规则](../workflow/context-reading.md)，按本页触发条件选资料，不批量加载整个目录。

这里帮助选择适用规范，不另立一套工程规则。先读[总索引](../index.md)，只追加当前问题需要的指南。

- 新增抽象、组件或合并实现：[代码复用](./code-reuse-thinking-guide.md)。
- 接口、状态、数据库或多个消费者变化：[跨层分析](./cross-layer-thinking-guide.md)。

工程约定和行为要求写入所属领域专题；产品契约留在 docs/OpenSpec。经验需有明确触发条件、可复用预防和实现或测试证据；一次性过程留任务记录。
