# 前端验收

本页规定验收行为；测试设计、隔离与执行方法见[前端测试](../testing/frontend-testing.md)，
检查选择与交付门槛见[测试入口](../testing/index.md)。先检查相关组件/调用方，再扩大到共享影响范围。

## 工程与组件

1. 按改动运行 typecheck、lint、相关单测和构建；共享行为扩大检查范围。
2. 修改 shadcn 配置时实际执行 CLI info 与代表组件 dry-run，检查目标路径、导入和依赖。
   不能产生 shared/ui/ui 等重复目录，也不能以 CLI 识别成功证明组件来源或交互正确。
3. 验证 focus、hover、disabled、busy、invalid、selected、open，及空/加载/错/无权限状态。
   状态有语义和文字，不只靠颜色；表单标签及错误关联可观察。
4. Tabs 检查方向键、Home/End、禁用项跳过、受控值与动态变更；无有效选中项仍可键盘进入，
   不自动触发选择回调。Select 检查选中与滚动；Dialog 检查 Escape、Tab 范围、焦点返回与嵌套 Portal。
5. 密度变化检查控件、表头/单元格横向对齐、卡片间距与字号；验证显式样式覆盖实际生效。

## 数据与交互行为

- 请求/筛选变化：旧响应不覆盖当前条件；加载、刷新、空结果、失败与无权限分别可辨。
- 会话/资源变化：私有数据和未完成写入不串到另一身份或资源，表单草稿按既定契约保留或重置。
- Mutation：成功状态、受影响缓存与列表一致；失败不留下伪成功；重复操作与并发失败恢复不覆盖较新结果。
- 取消/重试：只在此次改动涉及这些能力时验证其语义，不能用 signal 参数存在作为完成证据。
- 国际化：新增用户可见文字进入翻译资源，检查插值、空/长内容以及中英文布局；错误消息同样可翻译。

## 日志与诊断

- 需要记录的错误用 `console.error`，弃用提示用 `console.warn`；避免在生产代码遗留
  `console.log` 调试输出。日志不能替代用户可见的失败提示，也不要在客户端和调用方重复记录同一错误。
- 禁止输出 token、Cookie、Authorization、密码及包含这些字段的完整请求/响应对象。
  `console.error(error)` 也不是天然安全：先检查异常 message、cause 和附带上下文是否包含敏感数据。
- 需要定位请求失败时只选择已确认安全的字段，如操作名、HTTP 状态码；不要直接打印登录请求体、
  token 创建结果或完整 URL 查询参数。示例：`console.error('Token creation failed', { status: 500 })`；
  反例：`console.error('Token creation failed', response)`，后者可能带新生成的 token。
- 日志修改的验收：检查所有成功/失败分支的实际参数；涉及脱敏逻辑时用明显的假凭证标记驱动错误分支，
  spy 日志输出并断言该标记未出现。不能用真实凭证做 fixture。

当前 [ESLint 配置](../../../web/.eslintrc.cjs)没有 `no-console` 规则；lint 通过不代表完成上述检查。
日志级别与字段限制需在变更 diff 中审查，本页不宣称已有自动脱敏或前端日志平台。

## 动效验收

涉及动效变化时，读取[交互动效规范入口](./motion-guidelines.md)及其正文，
按正文第 7 节区分设计评审、功能验证、性能测量和真实用户研究。
验收范围与例外以正文为准，不以参数一致、截图或媒体查询存在代替验证。

## 视觉与页面

已采用设计系统时，按[采用规则](./design-system.md)对照实现与检查阶段相同的来源摘要。

选择并记录代表性桌面/移动视口，验证明/暗 × regular/compact。
检查页面无横向溢出、长中英文换行、字体加载、字重、对齐、控件层次和减少动态偏好。
共享字体/主题/组件变化检查代表登录、搜索、技能详情和管理页，实际页面按检出选择。
固定 API 响应可作 UI 回归，不代表真实后端或生产验收。

个人预览保持紧凑首屏；额外字体层级、间距、圆角、阴影、状态及组合样例可折叠，
验收时展开检查，不因首屏精简丢失覆盖。预览用当前工程组件，局部适配与共享默认有明确区分。
预览路径、端口、版本和启动命令属于当前任务的运行记录，不是所有工作树的固定能力。

## 证据与隔离

- 每次报告记录仓库/基线/diff、命令、实际运行环境和结果，不继承其他检出的通过记录。
- 浏览器启动失败、业务断言失败、未运行分别记录；源码字符串断言或截图存在不能替代交互/视觉检查。
- 截图检查后才作参考；基准标注预览版本、浏览器、视口、主题、密度、固定输入与字体/动画条件。
  确认原型落地时，在相同内容视口对照页面组合、关键尺寸与锚点；宿主侧栏不计入插件内容视口，
  功能测试通过不能替代还原度验收。标明实际Figma导出、节点回读重建图与运行截图的来源。
  像素差异先定位字体/动画等来源，不靠更新图片掩盖失败。
- 个人预览/截图/任务日志先验证未跟踪且被忽略；工程 fixture 与个人入口分离。
  生产构建不可暴露个人入口，截图和本机路径不能混入工程 diff。
- 官方 Skill 安装、当前会话读取、新会话发现、AGENTS 加载、hook 信任与实际触发分别验证。
  未信任 hook 不通过修改信任记录或绕过入口伪造通过。
- 任务的延期项有明确原因与后续命令；延期不是通过，也不自动变成永久豁免。

规范正文不包含个人预览、截图或任务运行状态；工程测试与 fixture 按仓库约定维护。
