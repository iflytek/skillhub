# SkillHub 视觉基础

适用于采用 React 19、Tailwind 3、现有 Radix 与 shadcn 源码体系的 UI 工作。
SkillHub 默认采用[设计系统](./design-system.md)中的已审阅目标；缺库不表示可以回退旧视觉。
以下保留历史产品基线以便理解存量差异，不覆盖目标主题、组件与规范；用户明确选择保留旧外观时再按范围使用。
这不是所有分支的实现声明。开始修改前核对当前源码、调用方和测试；
已具备能力、差异和验证结果记录在当前任务中。

视觉变量的工程来源是 `web/src/index.css`，映射是 `web/tailwind.config.ts`，
组件 API 和实际默认值以当前检出源码为准。规则不替代源码，也不授权全站重设计。

| 维度 | 默认与允许变化 | 使用边界 |
|---|---|---|
| 页面、表面、弹层 | background/card/popover 与各自 foreground 成对 | 黑白灰主调；避免页面硬编码白色使暗色失效 |
| 主要操作 | primary 保持近黑/近白；次操作 outline/ghost | 蓝色仅用于有限交互强调，不默认把按钮和卡片全改蓝色 |
| 状态 | info/success/warning/destructive 与 foreground 成对 | 同时提供文字或图标，不能只靠颜色表达状态；先核对变量是否存在 |
| 正文与标题 | 自托管 Inter 400/500/600/700；中文系统 sans 回退 | CSS 与 Tailwind 字体同源；核对实际加载资源，不假设未提供字重可用 |
| 代码与品牌 | 自托管 JetBrains Mono；既有品牌字体限品牌场景 | 品牌字体不作为正文；不增加运行时远程字体请求 |
| 字号 | 页面标题30/36px、区域20/28px、卡片18/28px；正文16/24或14/20px；辅助12/16px | 使用有限尺度；长标题允许换行，场景需要可调整，不以缩字解决拥挤 |
| 字重 | 正文400、表单/次标题500、主要标题600、少量700 | 符合已加载字体字重；中文平台差异需在视觉检查中记录 |
| 间距 | 内部8/12px、字段16px、分组24px、页面区块32px | 使用 gap-2/3/4/6/8；例外按布局场景解释，不增加无人使用的变量 |
| 密度 | regular 控件36px/单元格12px/卡片20px；compact 32px/8px/16px | 设计基线；容器 data-density=regular/compact，使用前确认变量与组件已实现 |
| 尺寸例外 | sm、lg、icon 沿用当前 API；Textarea 不跟随单行控件压缩 | compact 保持默认文字可读；触屏按需求使用常规或更大操作区域 |
| 圆角 | sm=8px、md/lg=10px、xl=14px、2xl=18px；标签可full | 复用 --radius 与既有映射；文档不能声称同值的 md/lg 不同 |
| 边框与阴影 | 边框分组、轻阴影表面、较高层级弹层 | 不给每层嵌套容器加重阴影；检查 className/style 覆盖是否实际生效 |
| 动效 | 控件反馈默认150ms是项目基线；有依据的场景可调整，非必要装饰不新增 | 涉及动效时读取[交互动效规范入口](./motion-guidelines.md)及其正文；按通用规范验证减少动态与交互行为 |
| 响应式 | 页面边距移动约16px/桌面约32px，工具栏换行，表格内部横滚 | 长无空格内容可换行；弹层不超视口；页面不能横向溢出 |
| 主题、焦点与错误 | 明暗状态成对；可见 focus；aria-invalid 关联错误文字 | 不移除焦点提示；错误不能只改变边框颜色 |

正确：在密度实现已具备的管理表格容器上设置 `data-density="compact"`。
错误：每个按钮分别写任意高度，并把默认正文缩成10px。
正确：成功颜色附“已发布”文字。错误：仅用一个绿色圆点表达审核结果。

## 密度与局部定制

表头与数据单元格横向 padding 应使用同一密度来源。Portal 不自动继承触发器局部
容器的密度，Select/菜单选项须保留可达尺寸；全局密度与局部紧凑分别验证。

单页面宽度、排列、文本域高度、按钮留白和标题字号可以在调用处调整。
个人预览的局部适配不升级为全站默认；只有多处产品需求成立才按
[组件规则](./component-guidelines.md) 增加共享变体。
兼容类与营销页面现有特例不自动成为新页面模板，也不因此批量清理存量。
