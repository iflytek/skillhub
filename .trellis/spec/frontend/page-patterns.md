# 页面组合

先读[视觉基础](./visual-foundations.md)和[组件目录](./component-catalog.md)。
这些模式指导组合，不授权全站或特定页面重设计。示例组件在当前检出存在时复用，
不存在时先核对实际能力；不为对齐文档名字迁移业务代码。
已选设计系统时，按[采用规则](./design-system.md)追加其页面组合正文；以下通用模式不覆盖
选定设计中的任务布局、密度和尺寸。需要 Figma 审阅时按[设计证据](./design-evidence.md)留存。

- 搜索：标题/输入 → 筛选/排序/结果数 → 结果列表 → 分页。输入有可访问标签，
  窄屏工具栏换行。技能卡片、分页、空态和骨架优先复用。元数据按信息优先级展示，
  不全部变成彩色徽标；空结果给清除筛选动作，失败给重试。
- 详情：标题/来源/版本 → 安装主要操作 → 文档、版本、文件分区。
  复用安装命令、复制与 Tabs；长名称/命令可换行或内部滚动。
  安装与草稿权限遵循既有业务规则，UI 基础不能改写权限。
- 表单：关联的 Label → Input/Select/Textarea → 帮助或错误 → 主次操作。
  错误用 aria-invalid 与 aria-describedby；提交中防重复并附文字，失败保留输入。
  权限错误单独说明，不能冒充空结果。
- 管理列表：页头/主要操作 → 工具栏 → Table → Pagination。
  局部 compact 适合高信息密度列表，表格内部横滚。行操作不抢占主要任务；
  危险确认显示明确对象名称，保留取消路径并复用已有确认能力。

常规页面区块使用有限 gap-6/8、字段 gap-4、操作 gap-2；场景需要可调整。
空态与加载态分别处理，骨架调用方提供可访问加载说明。
复用已有标题、分页、复制、确认和骨架，不引入重复组合或包裹一切的空抽象。
