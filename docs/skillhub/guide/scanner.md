# Skill Scanner 安全扫描

SkillHub 可在技能包发布后自动触发安全扫描，帮助团队在审核前尽早发现风险。

## 对用户可见的行为

- 发布后可能先进入扫描阶段
- 扫描结果会展示在技能包详情页
- 审核人员会结合扫描结果做决策

## 典型用途

- 发现恶意代码或异常行为
- 识别敏感信息泄露风险
- 辅助审核人员快速定位高风险包

## 你需要知道的事实

- 扫描通常是异步执行的
- 是否启用扫描由部署方决定
- 不同环境下启用的扫描引擎可能不同
- 扫描结论是治理输入，不等于自动替代人工判断

## 作为发布者的建议

- 发布前先清理无关文件和测试残留
- 避免把凭证、密钥、调试数据打进包内
- 如果扫描失败或被标记高风险，优先检查包内容而不是反复重发

## 作为管理员的建议

- 先看高严重级别结论
- 再结合文件浏览和审核上下文判断
- 对误报和真实风险分别沉淀处理经验
