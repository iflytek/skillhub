# 前端动作统计

默认不采集、不加载统计 SDK。当前提供**手动接入示例**；通过 Docker／Compose 或 Helm 配置直接开启的能力尚未合并。点击事件只表示操作意图，不证明下载、发布或执行成功。

## 如何接入

1. **选平台**：已有平台可复用；没有平台可先运行隔离的 Umami 演示。不要把演示密码用于生产。
2. **配置采集**：准备有效网站 UUID、需要采集的动作与明确授权判断；部署方维护采集入口、适配器和代理。
3. **验收再开放**：检查请求字段和真实入库，并验证关闭与平台故障不影响正常业务。

[详细操作指南（中文）](./frontend-analytics-guide.md)提供命令、规则、子路径与恢复步骤；[接口与隐私契约（英文）](./frontend-analytics-reference.md)定义事件及适配器边界。

## 验收看什么

| 场景 | 应观察到什么 |
| --- | --- |
| 默认关闭 | 不加载统计 SDK、不发送事件，业务正常 |
| 已启用且获得授权 | 一次动作一条对应事件，平台确实入库；不传搜索词或身份字段 |
| 启用后平台故障 | 请求失败但搜索、技能页面仍可用 |
| 平台恢复 | 刷新页面后新事件能入库，丢失事件不保证补发 |

## 常见问题

- **没有数据？** 核对是否走了示例 edge 入口、授权、网站 UUID、规则和缓存；HTTP 200 不等于已入库。
- **任意平台都能只填地址吗？** 不能。其他平台还需适配器和经过审核的代理端点。
- **算匿名采集吗？** 精简 JSON 不等于匿名；平台仍可能收到 IP、User-Agent 等传输信息。部署方负责访问控制、保留期限与合规。

## 如何关闭

当前页可用 `window.skillhubAnalytics.stop()` 停止后续派发，已发出的请求不能撤回。持续关闭需将入口恢复为 `enabled: false`、重新创建 edge 并禁用缓存刷新；完全撤掉接入则移除注入／edge，回到原 Web 入口。隔离演示的清理步骤见详细指南，不要清理共享平台或业务数据。
