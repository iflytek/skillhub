# 收藏、评分与通知

## 功能描述

SkillHub 提供了丰富的社交功能，让团队成员可以互动、分享、推荐技能包。

![概念图](/diagrams/social-concept.png)

**核心功能**：

- **星标（Star）**：收藏喜欢的技能包，方便后续查找
- **评分（Rating）**：给技能包打分（1-5 星），帮助其他人判断质量
- **下载统计**：记录下载次数，展示热门技能包
- **通知系统**：及时接收审核、成员及治理等事件通知

**社交数据**：

| 指标 | 说明 |
|------|------|
| **星标数** | 有多少人收藏了这个技能包 |
| **平均评分** | 所有用户评分的平均值 |
| **下载量** | 累计下载次数 |
| **更新时间** | 当前列表显示的更新时间 |

## 使用场景

**场景一：收藏常用技能包**

开发者发现一个好用的技能包，点击星标收藏。

**场景二：评分推荐**

使用技能包后，给出评分和评价，帮助团队其他成员。

**场景三：查看通知**

收到审核通过的通知，或其他受支持的治理事件通知。

**场景四：浏览热门**

查看星标数最多、评分最高的技能包，学习最佳实践。

## 使用步骤

**星标技能包**：

1. 访问技能包详情页
2. 点击「Star」按钮
3. 技能包会出现在「我的收藏」列表中
4. 再次点击可以取消星标

**评分技能包**：

1. 访问技能包详情页
2. 点击星星图标选择评分（1-5 星）
3. 评分会立即生效，影响技能包的平均评分
4. 可以随时修改评分

**撰写评价**：

1. 在已发布技能的详情页点击「写评价」
2. 选择 1-5 星并填写最多 2000 字的评价
3. 可以修改或清空评价；清空评价不会删除星级评分，即使技能之后取消发布也仍可清空自己的文字
4. 被管理员隐藏的评价在重新编辑后仍保持隐藏，只有技能管理员或超级管理员可以恢复公开

**查看通知**：

1. 点击顶部导航栏的通知图标
2. 查看未读通知列表
3. 点击通知跳转到相关页面
4. 标记为已读或全部已读

通知列表和未读数每 10 秒通过普通 HTTP 请求刷新，并在窗口重新获得焦点时立即刷新。旧版
`GET /api/v1/notifications/sse` 接口已移除；自建客户端应改为轮询
`GET /api/v1/notifications` 和 `GET /api/v1/notifications/unread-count`。

**查看我的收藏**：

1. 访问 `/dashboard/stars`
2. 查看所有星标的技能包
3. 分页浏览收藏列表；需要筛选时到搜索页启用“仅收藏”
4. 快速访问常用技能包

## 操作前确认身份

收藏、评分和通知属于当前登录账号。匿名点击收藏或评分会触发登录提示；切换账号后请重新检查状态。收藏不会安装技能，取消收藏不会删除本地安装。评分按钮在请求期间禁用，提交成功后才刷新自己的评分及技能数据，悬停预览星数不代表保存成功。

## 管理通知而不遗漏处理

打开 `/notifications`，按全部、发布、审核、提升或举报分类查看，每页最多 20 条。点击未读项会标记已读并跳转到关联对象；通知本身不是执行审核批准的按钮，仍需在目标页面完成操作。

可以将通知全部标为已读；删除按钮仅用于已读通知。若希望减少提醒，打开 `/settings/notifications`，按分类调整站内通知开关。当前表单配置的是 `IN_APP`，不是邮件或短信订阅；没有保存偏好时默认开启。

## 确认结果与排查

| 操作或现象 | 可观察结果 / 下一步 |
| --- | --- |
| 收藏成功 | 按钮切换为已收藏，随后在“我的收藏”确认 |
| 修改星级 | 等待请求完成，核对“你的评分”；不要把悬停效果当成提交 |
| 清空评价 | 文字被清除，原有星级仍保留；这是不同于取消收藏的操作 |
| 自己能看到评价，公开列表没有 | 检查是否被隐藏；作者编辑不会自动恢复公开 |
| 通知仍显示旧未读数 | 等待轮询或重新聚焦窗口；仍异常时检查请求和登录状态 |
| 通知目标不可访问 | 重新核对资源当前状态和权限；历史通知不会恢复已失去的访问权 |

## API 接口

**星标技能包**：
```bash
PUT /api/v1/skills/{skillId}/star
```

**取消星标**：
```bash
DELETE /api/v1/skills/{skillId}/star
```

**检查星标状态**：
```bash
GET /api/v1/skills/{skillId}/star
```


**评分技能包**：
```bash
PUT /api/v1/skills/{skillId}/rating
Content-Type: application/json

{
  "score": 5
}
```

**参数说明**：
| 参数 | 类型 | 说明 |
|------|------|------|
| skillId | number | 技能包 ID（路径参数） |
| score | number | 评分（1-5，必需） |

**获取我的星标**：
```bash
GET /api/v1/me/stars?page=0&size=20
```

**获取我的评分**：
```bash
GET /api/v1/skills/{skillId}/rating
```

**评价接口**：

```bash
# 公开评价列表
GET /api/v1/skills/{skillId}/reviews?page=0&size=20

# 查看、创建或修改自己的评价
GET /api/v1/skills/{skillId}/reviews/me
PUT /api/v1/skills/{skillId}/reviews/me

# 清空评价文字并保留星级评分
DELETE /api/v1/skills/{skillId}/reviews/me

# 技能管理员或超级管理员隐藏、恢复评价
POST /api/v1/admin/skill-reviews/{reviewId}/hide
POST /api/v1/admin/skill-reviews/{reviewId}/restore
```


响应使用统一 API 封装。`GET .../star` 的 `data` 是布尔值；`GET .../rating` 返回 `score` 和 `rated`。修改接口返回空 `data`，不会返回评分时间。技能 ID 为数值。

## 注意事项

> **评分规则**：每个用户对每个技能包只能评分一次，可以修改评分但不能删除。

> **评价规则**：只有已发布技能可以评价；公开列表只显示可见评价。并发修改发生冲突时，刷新详情后重试。

- **星标数量**：技能包的星标数会显示在搜索结果和详情页
- **平均评分**：平均评分供选择技能时参考，不是搜索页的独立排序选项
- **通知设置**：用户可以在设置中关闭某些类型的通知
- **下载统计**：已发布版本的下载会记录计数；审核预览下载不计入公开下载统计
