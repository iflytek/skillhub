# 命名空间与团队管理

命名空间是 SkillHub 的核心组织单元。它决定团队边界、权限范围和治理责任。

## 角色模型

| 角色 | 典型职责 |
|------|----------|
| Owner | 完整控制命名空间和成员 |
| Admin | 管理成员、审核技能、维护设置 |
| Member | 发布和使用命名空间内技能 |

## 状态模型

- `Active`：正常使用
- `Frozen`：禁止继续发布新版本
- `Archived`：从主搜索路径中隐藏，不再作为活跃空间运营

## 日常操作

### 创建命名空间

1. 访问 `/dashboard/namespaces`
2. 创建命名空间并填写名称、slug、描述
3. 创建者默认成为 Owner

### 管理成员

1. 进入命名空间详情页
2. 打开成员页签
3. 添加成员或调整角色
4. 所有关键变更都应可追溯

### 生命周期治理

- 冻结：出现风险或需要临时停止发布时使用
- 归档：空间已经不再活跃但仍需保留历史内容时使用

## 使用建议

- 用稳定、短小、团队可识别的 slug
- 尽量减少 Owner 数量，保持责任明确
- 对外可见策略和审核策略应在团队内提前约定
- 定期清理无效成员和过期权限
