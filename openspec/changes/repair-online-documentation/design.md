## Context

审计基线为 2026-11-02 全站渲染快照。源码基线为包含 #1037/#1048 的 main。2026-11-03 最新公开 Release 为 [v0.2.25](https://github.com/iflytek/skillhub/releases/tag/v0.2.25)，不得将 main 已合并能力写成所有已发布实例均可用。

## Decisions

- 以 Controller、DTO、领域枚举/策略、CLI 命令和实际部署配置为事实源；每项新增技术说明给出对应稳定源码路径。
- 保持单一职责：第一批只修 P0，保留后续 IA/旧模板重构待办，不边修边移动目录。
- 状态按实际对象及字段解释。审计提到的枚举须重新核对；例如审核动作不代表必定存在同名任务枚举，头像可能包含多个状态维度。
- 权限表按空间类型、状态和身份展开，不把平台角色等同空间角色；后端返回的能力与业务前置仍须明确解释。
- Scanner 默认值与部署覆盖值放同一单元。诊断仅列目标变量，不输出整份环境、Secret 或含凭据的渲染清单。
- 操作示例标注工作目录、权限、可观察结果与失败下一步；坐标及域名为明确占位。
- 新内容按用户 C/D 约束写作；不以凑字数、套用失败模板或夸大保障代替必要事实。已有其他批缺口不得伪装为已完成。

## 第二批：深度基准样本（2026-11-03）

维护者确认第二批改造六个中文页面及对应英文页：项目简介、快速开始、命名空间、审核、收藏评分通知和安全扫描。第一批 PR #1054 尚未合并时，第二批独立分支以其冻结提交为基础实施，不混入第一批 PR，也不并行发布。

- 文体采用正式技术文档：完整、客观陈述，避免对话式问句、口语、营销语和无依据结论；不得使用第二人称。
- 内容增加来自判断依据、操作前置、可观察结果、异常处置和下游影响，不以字数、重复警告或罗列接口代替深度。
- 简介采用概念解释结构，说明注册中心的职责与边界、技能/技能套装/套装 Bundle 的区别及选择依据；不提前创建第三批公共知识页面。
- 快速开始采用教程结构，保留完整命令、结果样例和一次无破坏性的故意失败演示；不声称安装成功代表 Agent 执行成功。
- 四个操作页面移除旧模板结构，按角色分流，提供可执行步骤、完成标准、至少四行失败矩阵及限制。现有P0事实修正必须保留。
- 复杂流程或对象关系配合图示，权限/状态/故障条件使用表格；图示不替代可复制命令和文本解释。优先使用静态SVG，含可访问说明，兼顾390px与明暗主题，不引入渲染依赖。
- 第二批主体保持既有路由；维护者复核明确要求的头像部署新页及对应导航调整为例外，其余侧边栏顺序不变；新增正文链接用相对.html，英文正文对应英文页面。仅在六页范围整合内容，不擅自改写其他批次。
- 每页记录来源与D1九要素覆盖；不明确的保留期、权限、事件类别、扫描阈值必须查代码，不编造固定承诺。无固定值时明确配置来源或未定义行为。

验收：中文正文体量不超过3000汉字（参考/代码清单不以扩写为目标），没有禁用旧章节或空标题；中英结构/链接一致；所有新技术断言有稳定源码依据；OpenSpec、VitePress、正文链接/锚点及真实浏览器宽度/主题检查通过，一次集中独立Review完成后冻结。
