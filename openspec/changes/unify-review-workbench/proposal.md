# 统一审核工作台

## 原因

审核管理、审核与治理和命名空间审核重复呈现任务，范围与申请事项难以区分。审核详情仅展示原始包文档，无法完整核对版本化的自定义简介和概述；普通变更页仅有合规与历史，未表达展示内容变化。

## 已确认方向

统一审核中心和权限内队列。列表取消状态Tab，使用统一筛选区域：关键词、状态、范围、申请事项、来源以及查询/重置。桌面下拉176×32px，菜单同宽、选项32px；手机44px。详情使用已确认的双栏结构、项目token和胶囊内容导航。治理承载举报、全局提升、记录及独立治理通知，命名空间入口预选统一队列范围。

## 影响

扩展现有审核读接口和分页查询；不更改审核写入、权限、自审、扫描、发布或技能包内容。不增加数据库迁移与生产依赖。保留旧路由、旧接口消费者和独立用户资料审核。普通版本补展示文案与文件清单比较；GitHub原有逐行差异保持。
