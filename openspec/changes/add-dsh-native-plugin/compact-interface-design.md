# 紧凑设计系统界面与功能保真

## 目标与范围

将用户确认的Figma V4与紧凑Demo节奏落实到DSH插件。保留现有查询、写入、来源、会话、原操作恢复和库存兼容契约；原型遗漏的条件入口先补画再实现。视觉基线为中性黑白、语义状态色、32/28px控件、13px控件字、内容宽度按钮、273×192参考卡片（真实布局按容器响应）、指标16px图标/4px内距/12px组距。内容区域上方集中导航、搜索和筛选，不新增来源侧栏。

## 组件与边界

复用现有React18 Host externals、Radix/shadcn适配与TanStack Query，不升级运行依赖，不复制演示页脚本、预览CSS、私有库资源或本机路径。样式限定插件及其Portal，不能改变DSH宿主其他页面。图标在生产代码使用已有SVG方式，不复用Figma原生矩形近似图层。

目录/收藏/已安装使用同一视觉体系，但数据语义独立：完整来源收藏本地筛选，失效收藏仍可移除；不补造版本与指标、不批量解析。保留分页、排序、标签能力降级、失败/取消/重试更新检查、已安装刷新、多位置与其他来源判断，以及返回对话/原筛选和焦点。

详情保留官网webUrl条件、当前固定版本、文档、版本、只读评论、安全审核显示策略、使用技能与案例流程、全部安装管理。新增文件页后采用概览/文件/版本/评论四个主Tab，安全审核以受相同策略控制的独立入口打开，隐藏时不显示、不请求。安全审核不可读不能冒充通过。

操作面板保留原有受理/确认/失效/备份/恢复回执：先处理本地修改再展示版本变化；文件还原只针对当前安装，不提供升级后版本回滚；保留全部还原、新增文件删除确认、备份位置/复制、二进制/大文件/截断/不可用状态、历史操作/告警与核验并恢复。上一步回看同一个只读快照；继续仍由Host重验来源、快照有效期及文件，未变化时复用已核验备份，变化或过期后重新检查，不复用执行授权。安装/导入提交后的外壳分别保持432/448px（窄屏不超过视口减32px并内部滚动），关闭不取消已受理操作。启停、卸载、失效记录清理均按位置确认。

设置继续使用单一来源列表、草稿、当前使用/待保存、断开、行内编辑、三项auto/show/hide、测试结果、跨Tab保存/重置、revision CAS冲突和只读状态。

## 只读文件能力

Registry已经有精确版本files清单及file正文GET接口；本轮不新增SaaS HTTP接口。插件增加两个只读Host RPC（listSkillFiles/readSkillFile），绑定现有detailToken和sourceRevision，惰性读取精确版本文件清单及选中文本。清单最多500项且有路径/大小校验，正文最多256KiB并验证UTF-8，禁止任意URL/Host路径读取，不赋予安装权限；切源使旧引用失效。只读文本用转义pre展示，binary/过大/无权限/不支持/失效/错误分别反馈。局部文件缓存有界，不在目录卡片批量拉取。仅当前Registry固定版本支持此读取；本地导入/其他来源fallback不借用当前Registry内容。

## 验收与发布边界

以现有功能清单和行为测试逐项保真。运行插件构建、typecheck、lint、完整测试与新增只读RPC边界验证；使用真实隔离DSH Host检查目录、收藏、详情/文件、安装/导入/管理、设置、恢复及回到会话。检查1440/1024/390、明暗、长文本/缺指标/空错状态、键盘和Portal。固定数据预览不冒充现网验收。新增只读RPC需生成契约和既有RC兼容检查；不升级版本、不发布或自动合并。

用户人工Review指出文件区正文过小、层层灰底包框和文件行大块深灰选中/悬停影响阅读。文件页改为单一浏览工作区：约176–192px文件侧栏、主体占据剩余宽度；正文与侧栏分别滚动，移除正文内嵌灰色卡片和重复外边距。桌面工作区随视口约440–640px，正文占满工具栏以下区域；窄屏列表保持120–144px上限，正文仍保持有界阅读高度，不能无限撑页面或产生文档横向溢出。

选中文件使用浅蓝语义底色和细边指示，悬停用背景token，不将正文次级文字颜色用作背景；选中+悬停不能退化为深灰。暗色采用对应可读配色。文件路径、大小与计数保持真实，重复总量信息可合并进列表头；只读、复制、键盘焦点及大文件/二进制/UTF-8/无权限/失败/失效语义不变，不调整Host接口或字节上限。

验收以真实预览正文可视高度、hover/selected对比、长正文内部滚动及390px/暗色为依据；既有284px正文是旧设计，不能作为本轮还原目标。原型07的设计尺寸以本次人工Review后的上述规格为准，实时Figma同步需要单独读取确认，不能将代码变更描述为已写入Figma。
