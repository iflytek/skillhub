# 单技能包导入与导出

## 范围与交互

本轮只实现 DSH 本地单技能 ZIP 导入/导出，不增加 CLI 命令、服务端 API、登录或发布功能。复用现有 shadcn/Radix 控件及安装范围选择。运行环境检查暂缓。

- 已安装页面提供一个次要“导入技能包”入口。选择 ZIP 后，预览技能名称、简介、文件数和安装范围；用户明确确认后才安装。取消预览不安装，不执行包内脚本。
- 首期包的根目录必须包含单个 `SKILL.md`；不自动发现多技能、套件或嵌套根。采用 DSH 实际解析器验证，解析失败明确拒绝。
- 同名目标（包括手工技能、不同来源、停用目录、其他安装记录）存在时阻止导入，不提供覆盖或隐式改名。用户可选择另一范围，或自行处理已有技能后重试。
  对同一可信本地来源、相同指纹且未修改的现有安装，可以核验后返回已安装回执，不重写文件；这不允许替换不同内容或不同来源。
- 详情右侧“安装管理”的各位置使用明确的“管理＋下拉箭头”按钮进入原有菜单，增加“导出技能包”。点击即导出该位置，不使用省略号触发器，不在标题旁增加独立按钮，也不再次弹出位置选择框。安装位置以紧凑分隔行展示范围和状态标签，仅市场安装显示实际版本；本地导入不重复显示“本地技能”。同一技能存在多个位置时由用户打开对应位置菜单明确选择。导出实际文件而不是重新下载发布包，保留本地修改、二进制资源和 `.skillhub/examples.json`。
- 停用安装导出时只在 ZIP 内把 `SKILL.md.disabled` 还原为 `SKILL.md`，不改变原安装状态。包内同时出现两个入口则拒绝。
- 导入成功回到已安装列表并显示“本地导入”；可以使用、诊断、启停和卸载。它没有市场详情、市场版本更新或官网跳转；不凭名称或包内元数据认领 Registry 身份。

## 来源与兼容

导入来源由 Host 创建，不能由 ZIP 声明。内部本地来源标识不是可访问的 Registry 地址，禁止用于 HTTP 请求。导入记录保存在 DSH 私有状态目录，复用库存 v2 读写和目标锁，不能把新类型记录写入 CLI 共享库存或要求旧 CLI 升级。市场安装的库存、元数据和行为保持不变。

使用同一操作日志与恢复机制；本地导入操作复用既有扩展日志隔离目录，旧 DSH 普通日志扫描不会读取新来源记录；根据可信操作来源选择对应库存。读取已安装列表时合并两类可信投影，市场更新扫描仍只选择当前 Registry。旧 CLI 对导入目录的普通同名安装仍应拒绝覆盖。

## 文件及授权边界

- Client 只能上传 ZIP 字节、提交不透明预览引用和安装范围；导出只能提交已安装项引用，不接受任意宿主路径。
- ZIP 解析复用共享 archive 能力并补齐导入需要的拒绝规则：路径穿越、绝对路径、大小写冲突、重复条目、软链接/特殊文件、加密或不支持的归档、单文件/文件数/总展开体积超限。
- `.skillhub/metadata.json` 属于安装器内部状态，导出排除、导入拒绝。保留合法作者资源，不把整个 `.skillhub` 目录删除。拒绝携带已知内部事务/锁等保留路径；不声称能自动识别所有作者文件中的秘密。
- 传输有明确压缩包字节上限；解析、展开和导出也受既有文件数/单文件/总体积上限保护。错误不得把完整宿主路径或包内容回传给模型。
- 导出检查普通文件树，拒绝软链接及路径别名，并核对读取期间文件变化；不执行任何内容。
- 预览有期限，绑定会话、cwd、来源修订和 Host 实例；切换上下文后拒绝旧确认。导入执行重验包指纹、目标、策略及冲突，使用既有目标锁、事务日志和恢复，不增加独立文件事务实现。
- 默认导入“仅此项目”；两个范围的权限仍由 Host 的实际映射和 sandbox policy 决定。拒绝只读/越界，浏览器不能通过改 scope 绕过权限。

## Host 私有契约

三项 RPC 均受 `RemoteScope('agent')` 保护，不增加 SkillHub 服务端 HTTP API：

| 方法 | 输入与结果 |
| --- | --- |
| `previewPackageImport` | 来源修订、ZIP base64、取消信号；返回不透明预览引用、名称/简介、文件数/展开字节数和有效期 |
| `confirmPackageImport` | 来源修订、预览引用、范围、幂等请求键和取消信号；返回既有操作回执 |
| `exportInstalledPackage` | 来源修订、精确安装引用和取消信号；返回文件名与 ZIP base64 |

压缩包传输上限 8 MiB；Host 预览归档保留总量上限 32 MiB，预览有效期复用现有五分钟计划机制。Client 清理请求及结果时不撤销已受理文件事务。导入预览名称及长链接自动换行，完整简介保留在限高滚动区（桌面120px、窄屏96px）；短窗口只滚动内容区，安装范围与底部操作保持可见，下拉菜单不被内容区裁切。导入弹窗沿用安装/下载进度的视觉，预览与范围下方保留紧凑结果区；确认后显示真实阶段，完成回执显示“导入成功”，异常或回执不可读时显示待核验，不伪造百分比。安装范围提交后保留且锁定，完成前后高度保持稳定。仅核对到对应本地来源、技能、范围的完整可用安装后展示“使用技能”，点击时重新核对并走已有原生使用流程，不自动发送。导入弹窗关闭后恢复入口焦点；导出复用位置菜单的键盘与焦点行为，不增加弹窗；导入事务尚未结束、入口仍禁用时回退到列表搜索框。

## 验收

1. 含脚本、二进制与多语言案例的导出/导入往返逐文件字节一致，内部元数据不传播。
2. 本地修改被导出；停用安装导出后入口规范化但原文件不变。
3. 已存在目录、跨来源和用户/项目同名的冲突均不覆盖；只修改选择的位置。
4. 恶意/损坏/超限 ZIP 被拒绝，无目标文件和库存变更。
5. 取消、重复确认、会话/来源变化、权限变化及并发安装保持目标与记录一致；失败或中断可按既有机制恢复。
6. 导入项可使用、启停、诊断和卸载，不访问 Registry；市场来源功能及旧 CLI 库存 v2 兼容。
7. Host 契约、共享核心、UI 交互分别验证；实际 DSH 浏览器核对明暗、窄屏、键盘、上传与下载。未运行的模型/平台验收单独记录，不用静态截图替代业务验证。
