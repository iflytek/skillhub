## 7. 真实模型与宿主交互执行单

本节落实 5.3、6.6 的剩余验证，不用直接调用工具或合成历史消息代替模型行为。使用隔离 Web Profile、测试会话与工作目录，连接已批准的测试模型；模型凭证仅在本机 DSH 配置中提供，不进入截图、报告或仓库。先执行只读搜索用例，通过后再按序执行写入和异常用例。每例独立记录实际工具调用、操作 ID、文件变化与截图，不以自然语言“成功”作为通过依据。

| 用例 | 用户操作或输入 | 必须观察到的结果 |
| --- | --- | --- |
| 只读搜索 | “在 SkillHub 搜索 document 相关技能，只展示结果，先不要安装。” | 模型调用原生搜索工具并显示卡片；没有安装工具调用、安装操作日志或技能文件新增 |
| 歧义选择 | 提供至少两个实际候选后输入“装那个文档技能”，不指定目标 | 模型要求明确选择或引导打开详情；不能任意挑选候选写入 |
| 明确安装 | 从结果打开固定版本详情，选择当前项目并明确确认安装 | 参数来自已查看的候选和可信目标；先显示受理状态，后通过同一 operationId 展示终态；文件、资源与清单一致 |
| 无详情直接安装 | 搜索至少三个候选后直接输入“安装第二个到当前项目”，不打开详情 | 使用第二项原 selectionRef，Host 固定搜索时版本；openConversationDetail 与 acknowledgeConversationDetail 调用数均为0；实际 completed、文件哈希、库存、DSH发现分别核验。直接官方工具验收与真实模型验收分开记录 |
| 核验期间变化 | 未展示候选核验时改变来源/项目、发布新latest、使原版本不可用或产生展示歧义 | 上下文变化和版本不可用拒绝；新latest不改变所选版本；不绕过已展示快照歧义 |
| 模型使用资源 | 对已安装 document-helper 输入“使用刚安装的技能，按说明读取 references/note.md，并告诉我文件内容。” | 模型实际加载该技能并读取安装目录内的资源，回答与文件内容一致；仅识别技能名称或复述历史卡片不算通过 |
| 真实 Registry 技能使用 | 从已验证开源测试实例安装一个带资源、无外部执行副作用的真实技能，要求按其说明完成一个只读任务 | 记录真实技能坐标/固定版本、资源完整性、DSH 加载和模型使用证据；本地 document-helper 夹具不能替代此项 |
| 关闭详情 | 在搜索结果打开详情后直接关闭，不确认安装 | 没有隐式安装；焦点回到触发入口，搜索结果仍可用 |
| 停止等待 | 分别在工具受理前、安装已受理后点击 DSH 的停止按钮 | 受理前没有新增文件；受理后不谎报取消文件事务，能通过原操作查询实际结果；区分宿主停止、工具 signal 和事务生命周期 |
| 断线重开 | 安装受理后断开浏览器连接，再打开原会话 | 原回执与当前操作状态可关联，无第二次安装提交；历史记录不伪装为新操作 |
| 失效记录 | 显式移除测试技能目录后重开原卡片，再尝试安装或清理 | 显示实际缺失状态；不能直接用历史引用覆盖或删除未知路径；按现行确认流程处理 |

前四项使用现有 catalog-fixture 的 document-helper，资源路径为 `references/note.md`，基础版本内容为 `Native installation resource`。停止/断线用例需受控延迟夹具以准确区分受理边界，不靠点击时机猜测。真实 Registry 用例另选已审阅的只读技能。对话升级和卸载不是首期模型工具范围，不在这些用例中添加新能力。

模型调用前需要确认可使用的本机测试配置与调用额度；未获得授权时保持未验证。该依赖不阻止继续整理本地证据、文档和不调用模型的检查。macOS 按用户决定延后验证，不作为本轮验收阻塞项，状态保持“未验证”，不得列为已支持平台。远程 Host 仍需要对应测试环境，不以本机 WSL 或浏览器夹具替代。


### 7.1 模型验收记录原则

模型回合、直接官方工具调用及浏览器状态投影分别记录。真实模型搜索和明确安装已有历史验证；当前展示样式调整不重复消耗模型调用。无详情直接安装的官方工具核验，不能单独替代模型完整回合；具体已验证范围见[验证摘要](verification.md)。

| 编号 | 输入与动作 | 应观察结果 | 当前状态 |

### 42.8 分组与场景操作增量验收

以下是本轮需验证的准则，不沿用早期逐行 UI 的通过结果：

- 同一来源与技能身份只展示一次；同名不同 namespace 不合并。同 scope 多目标保留且选中标签与确认一致。
- 用户/项目版本随选择显示，按钮使用对应引用；在检查未完成时切位置，迟到结果不能更新另一目标。
- 单份无 Tab，正常无刷新；低频操作在更多中，更新检查/确认/终态仅出现相关按钮。
- 确认目标锁定，取消不写；变更仅影响选定位置，另一份文件与库存不变。
- 旧引用仍拒绝；重新查询只读替换内容，不能自动执行旧意图。
- 部分读取失败不视为未安装；本地修改、共享归属、同名覆盖及禁止用户调用保持原边界。
- 双支持 RC 验证实际组件，深浅主题和窄屏无目标截断，菜单键盘操作和关闭后焦点可用。
- 原型场景截图与正式宿主结果分开保存；本轮未调用模型时明确说明，不重写既有真实历史。
