## 2. 实施阶段依赖

```mermaid
flowchart LR
  M0[M0 发行兼容与最小贯通] --> M1[M1 两入口只读体验]
  M1 --> M2[M2 日志恢复与双入口安装]
  M2 --> M3[M3 受保护升级卸载]
  M3 --> M4[M4 实机打包和平台验收]
  M4 --> R[交付可审查产物与限制清单]
```

| 阶段 | 出口条件 | 未通过时 |
| --- | --- | --- |

## 7. 真实模型与宿主交互执行单

本节落实 5.3、6.6 的剩余验证，不用直接调用工具或合成历史消息代替模型行为。使用隔离 Web Profile、测试会话与工作目录，连接已批准的测试模型；模型凭证仅在本机 DSH 配置中提供，不进入截图、报告或仓库。先执行只读搜索用例，通过后再按序执行写入和异常用例。每例独立记录实际工具调用、操作 ID、文件变化与截图，不以自然语言“成功”作为通过依据。

| 用例 | 用户操作或输入 | 必须观察到的结果 |
| --- | --- | --- |
| 只读搜索 | “在 SkillHub 搜索 document 相关技能，只展示结果，先不要安装。” | 模型调用原生搜索工具并显示卡片；没有安装工具调用、安装操作日志或技能文件新增 |
| 歧义选择 | 提供至少两个实际候选后输入“装那个文档技能”，不指定目标 | 模型要求明确选择或引导打开详情；不能任意挑选候选写入 |
| 明确安装 | 从结果打开固定版本详情，选择当前项目并明确确认安装 | 参数来自已查看的候选和可信目标；先显示受理状态，后通过同一 operationId 展示终态；文件、资源与清单一致 |
| 模型使用资源 | 对已安装 document-helper 输入“使用刚安装的技能，按说明读取 references/note.md，并告诉我文件内容。” | 模型实际加载该技能并读取安装目录内的资源，回答与文件内容一致；仅识别技能名称或复述历史卡片不算通过 |
| 真实 Registry 技能使用 | 从已验证开源测试实例安装一个带资源、无外部执行副作用的真实技能，要求按其说明完成一个只读任务 | 记录真实技能坐标/固定版本、资源完整性、DSH 加载和模型使用证据；本地 document-helper 夹具不能替代此项 |

模型调用前需要确认可使用的本机测试配置与调用额度；未获得授权时保持未验证。该依赖不阻止继续整理本地证据、文档和不调用模型的检查。macOS 按用户决定延后验证，不作为本轮验收阻塞项，状态保持“未验证”，不得列为已支持平台。远程 Host 仍需要对应测试环境，不以本机 WSL 或浏览器夹具替代。
