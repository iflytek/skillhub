## 1. 产品定义和范围

### 1.1 一句话定义

在 DSH 内安装 SkillHub 原生插件，获得一个可匿名浏览、搜索、查看详情、安装、升级和卸载技能的 **SkillHub 技能广场**。用户完成安装后回到原会话，由 DSH 使用技能。

SkillHub 网站负责发布、审核与维护内容；Registry 提供技能数据与包；插件负责发现与安装入口；DSH 负责工作区、会话、发现和执行。插件没有自己的聊天页，也不替换 DSH 的模型和会话；通过宿主工具和自定义结果卡片接入现有对话。

### 1.2 用户与场景

| 用户场景 | 用户目标 | 本版提供 |
| --- | --- | --- |
| 首次使用 | 看看有哪些技能可以使用 | 打开即展示真实技能列表，无登录步骤 |
| 已有明确任务 | 找到某类技能，例如 PDF 文本提取 | 关键词搜索、用途摘要和详细说明 |
| 安装前判断 | 确认技能内容、版本与安装位置 | 独立详情页及明确的范围选择 |
| 完成安装 | 知道是否装好，回到任务继续工作 | 文件安装与 DSH 发现分别反馈，返回会话 |
| 远程运行 DSH | 将技能装到远程 DSH 而非本机浏览器 | 明确显示当前 DSH 主机与可信目标 |

### 1.3 必做与不做

| 本期必须交付 | 明确不在本期 |
| --- | --- |
| DSH 原生包、一个 SkillHub 入口 | DSH 插件市场、网站重构 |
| 匿名列表、关键词搜索、详情 | 登录、Token、私有访问、账号与权限管理 |
| 默认用户级，可选可信当前项目 | 任意安装路径、多目标批量安装 |
| 完整安装、主动升级、精确卸载、冲突保护 | 自动更新、降级、强制覆盖本地修改 |
| 一个来源地址的必要配置 | 多来源聚合、认证中心、收藏和排行榜 |
| 对话搜索卡片、详情抽屉、显式安装工具、结果卡片 | 自动发现后安装、模型自主升级卸载 |
| 已安装管理、可选版本/审核/评论 Tab | 发表评论、扫描触发、自动运行技能、自动重启 |

“只做浏览和安装”仍包括完成安装所必需的错误反馈和文件保护。服务端和宿主现有策略继续生效；插件不建设权限产品，也不绕过拒绝。

### 1.4 产品成功条件

用户无需登录或手工安装 SkillHub CLI，能够在 DSH 内完成一条真实技能的浏览、详情、安装和返回会话路径。验收覆盖技能包完整性、安装记录一致性、宿主发现与后续使用。

## 2. 交互形态选择

广场入口选用 **主内容区内独立详情子页面，左上角返回技能广场**；对话入口新增 **详情抽屉**，窄屏改为内容区全宽浮层。以下比较仅适用于广场；对话交互以 [对话设计](conversation-design.md) 为准。

| 方案 | 好处 | 限制 | 本版决定 |
| --- | --- | --- | --- |
| 居中弹窗 | 打开快，保留背景 | 长说明与安装状态容易挤在小区域，窄屏需重做 | 不采用 |
| 右侧抽屉 | 可以快速比较列表项目 | 占用已有 DSH 面板空间；长说明阅读宽度不足 | 暂不采用 |
| 详情子页面 | 阅读完整，安装状态稳定，窄屏自然适配 | 返回多一步 | 采用；保留列表状态弥补切换成本 |

这里的子页面是 SkillHub 主面板内部的页面状态，不是跳到外站，不默认创建浏览器全局路由，不替换 DSH 会话。详情中的安装信息卡只是页面内容，不是宿主右侧抽屉。

## 3. 信息架构和导航

```mermaid
flowchart TD
  D[DSH 工作区与会话] --> S[SkillHub 入口]
  S --> B[技能广场]
  B --> Q[关键词搜索结果]
  B --> X[技能详情子页面]
  Q --> X
  X --> I[安装中]
  I --> R[详情内安装结果]
  R --> B
  X -->|左上角返回并恢复列表| B
  B -->|返回会话| D
  X -->|返回会话| D
  C[DSH 插件详情配置] --> A[单个 Registry 地址]
  A --> B
```

- 宿主侧栏持续显示品牌、工作区和会话；插件入口命名“技能中心”，配专用模块组合 SVG 图标。页面内部保留 SkillHub 品牌。
- 广场上方使用紧凑工具栏显示 SkillHub 和当前位置；来源通过信息入口查看，不常驻显示整行 URL。右上角 X 关闭插件主面板回到会话，并提供明确可访问名称。
- 详情左上角显示“返回技能广场”，右上角保留关闭 X。前者回目录，后者离开插件主面板；二者均不取消已经接受的 Host 操作。
- 广场常驻“浏览技能 / 已安装”两个 Tab；不设插件市场和账号入口。详情常驻“详情”，版本、安全审核、评论按实例配置显示。
- 从目录返回详情、返回会话再打开 SkillHub，当前 Client 生命周期内保留查询与浏览位置；浏览器刷新后重新加载，不承诺持久化页面历史。
- 没有活动会话时不显示返回会话的关闭动作；用户可用宿主“新会话”。

## 4. 页面 P1：技能广场

![技能广场设计图](assets/dsh-mvp-v3-catalog.png)

### 4.1 页面区域

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 工具栏 | 紧凑标题、来源信息入口、关闭 X | 来源是配置实例的显示地址/标签；关闭动作沿用宿主会话能力，无登录状态 |
| 搜索区 | 输入框、清空、搜索按钮 | Enter 与按钮行为一致；按提交查询，不逐字触发网络请求 |
| 结果说明 | 当前返回 N 项 | 如 total 可信且大于 N，可写“共匹配 T 项，当前显示 N 项” |
| 卡片网格 | 图标、slug/名称、完整坐标、摘要、版本、查看详情 | 卡片不提供安装按钮，避免跳过判断 |
| 空/错误区域 | 原因与恢复动作 | 不用空列表掩盖接口错误 |

### 4.2 卡片字段与紧凑布局

采用已确认的紧凑头像卡片，常规桌面字号下卡片高度 192px；主内容区宽屏三列、中等宽度两列、窄屏一列。保留 DSH 导航外壳，不复制原型中的模拟会话侧栏。

- 左侧 38px 头像，右侧技能名称和坐标。当前开源目录没有技能头像字段，使用名称首字符；英文转大写、中文取首字，空名称依次回退 slug、`?`。颜色由技能坐标稳定确定，不使用随机色、背景封面或作者头像冒充技能头像。
- 标题优先 displayName，缺失回退 slug，15px/20px、字重 600；坐标 12px/18px，单行省略但可通过完整提示和详情读取。
- 摘要 13px/20px，最多两行；空摘要显示“暂无简介”。系统字体优先继承 DSH，保留中文系统字体回退；不用等宽小字或缩放卡片实现悬停。
- 版本取 `publishedVersion.version`，不使用可能指向草稿的 headlineVersion。无发布版本的条目不提供安装卡片。
- 底部单行展示下载量、收藏数、评分及详情入口。三个指标独立可选；缺失、null 或非法值隐藏，下载量/收藏数为 0 时显示 0，无评价不显示 0 分。评分只读，不增加收藏或评分写操作。
- 数量小于 10000 使用千分位，大于等于 10000 使用“万”；提示和可访问名称保留完整数值。增加指标不增加卡片高度。
- 整张卡片只有一个明确的详情打开动作，避免嵌套按钮。浏览列表不逐卡请求指标或扫描本地目录。

### 4.3 浏览与搜索规则

初始查询为空关键词，通过现有匿名 GET `/api/web/skills` 每页读取 12 项，默认 newest；支持下载量 downloads、评分 rating 排序。底部“加载更多”主动请求下一页，不自动无限滚动、不提高 limit 模拟分页。显示来源匹配数及实际已展示数量；无发布版本条目被过滤时，两者可以不同。

搜索提交前去掉首尾空白；新查询或排序变化从第 0 页开始，查询键包含来源版本、关键词和排序。详情返回保留已加载页、查询、排序、滚动及焦点。重复坐标合并；后续页失败保留已有卡片并提供重试。来源变化后旧响应不能覆盖新来源内容。

若首批分页列表返回 404/405，回退 CLI 搜索，单次最多 20 项；明确标注“来源仅支持首批搜索”，不显示加载更多或宣称排序生效。401/403、429、网络错误、格式错误及后续页错误不得被当作旧来源静默降级。筛选使用实例公开标签，不硬编码原型中的演示分类。选择标签后不允许回退成无过滤搜索；失败时保留筛选条件并提示，可主动清除标签恢复普通浏览。

## 5. 页面 P2：技能详情子页面

![详情子页面设计图](assets/dsh-mvp-v3-detail.png)

### 5.1 布局

主内容区整体切换为详情页面，保留 DSH 外壳。上方是返回导航和技能身份；下方左侧为统一内容卡，容纳“详情 / 版本 / 安全审核 / 评论”Tab 及其内容，右侧为页面内部安装信息卡。内容卡桌面端 Tab 主体最小高度 440px，短内容保留结构、分页置底，长内容自然增长；窄屏取消桌面最小高度约束。默认正文是技能说明。窄窗口按“身份 → 说明 → 安装”单列排列。安装信息卡不固定覆盖正文。

### 5.2 内容和数据规则

| 信息 | 来源与规则 |
| --- | --- |
| 名称、坐标、摘要 | 搜索快照先展示；详情返回后校正，不修改所选身份 |
| 安装版本 | 打开详情时 resolve 一次获得精确版本；后续文档与安装绑定该版本 |
| 技能说明 | 读取该版本 SKILL.md，安全渲染 Markdown；保留技能原文，不用 AI 自动补写功能 |
| 使用方式/注意事项 | 原文有才展示；图片中的章节仅为示例，不要求后端返回这些独立字段 |
| 来源 | 当前配置实例，不展示内部带查询参数的下载链接 |
| 安装范围 | 用户级默认；当前项目可确认时提供项目级 |
| 可安装性 | 目标检查、包兼容性及下载可能分别失败，详情可读不等于可安装 |

说明缺失或读取失败时显示“详细说明暂不可用”及重试。只要精确版本 resolve 可用，可继续尝试安装；安装仍需完整包校验。若技能本体变为不可访问或 resolve 失败，则禁用安装。

Markdown 不执行 HTML/脚本；外部链接明确打开新页面，阻止危险 URL scheme；首版不自动加载远程图片，避免查看说明产生额外网络跟踪。相对资源预览不在本期，不影响完整包安装。

### 5.3 详情 Tab 规则

| Tab | 展示内容 | 版本语义与限制 |
| --- | --- | --- |
| 详情 | 摘要与 SKILL.md | 当前详情固定版本的说明，常驻 |
| 版本 | 版本号、发布时间、发布说明、可下载状态，实际分页 | 可选择可下载版本查看并安装；选择后重新读取精确版本说明与安装凭据，再明确确认安装。已有其他版本时保留冲突保护，升级通过已安装目标计划完成，不提供降级覆盖 |
| 安全审核 | 扫描器、审核时间、结论与发现项，按实际字段 | 只属于当前版本；无结果不等于安全；不能触发扫描 |
| 评论 | 公开作者显示名、评分、正文、时间和分页 | 现有接口按技能聚合，不伪装成版本专属评论；不提供输入框、回复、点赞或删除 |

版本、安全审核、评论支持 `auto / show / hide` 实例级配置，放在宿主插件配置内。开源和 SaaS 使用同一插件，不按产品名称硬编码。比如 SaaS 未上线评论时设置 hide，开源实例可在匿名读取已验证后 auto 展示。

`auto` 只有确认支持匿名读取才展示；`show` 保留入口但错误仍如实展示；`hide` 不展示且不请求。空数据保留 Tab 并显示“暂无版本/评论/审核报告”，网络错误保留重试。未知能力不能被当作“没有数据”。 auto 探测未确认时，在详情内容上方说明对应模块尚未确认，并提供“重新检查可选内容”；点击重新读取当前固定版本详情并探测未确认模块。确认可用后显示对应 Tab，正文仍在激活时读取。详情永不隐藏；隐藏当前选中 Tab 后回到详情。详见 [接口配置规则](interface-design.md)。

**当前源码限制：安全审核 Controller 明确拒绝匿名访问。** 默认 auto 下隐藏；显式 show 时显示“当前来源的审核信息不支持匿名读取”。本期不改后端访问政策、不增加登录。下图展示可选模块已启用且可匿名读取、但当前版本暂无报告的假设实例，不代表当前仓库已经支持匿名审核。

![安全审核可选 Tab 状态设计](assets/dsh-mvp-v3-tabs.png)

### 5.4 安装范围

- 用户级：“安装到当前 DSH 主机”。实际目标由 Host 解析，不能在浏览器拼接 home。
- 项目级：“仅用于当前项目：项目名”。没有可信项目根时禁用，并解释“当前没有可用项目”。
- 项目切换后旧目标失效，安装按钮提示重新确认当前目标；不能悄悄把旧项目的操作迁到新项目。
- 首版一次只安装一个目标，不做“全部 Agent”或 Suite 整套安装。

### 5.5 安装提交

按钮显示“安装到用户级”或“安装到当前项目”。点击后先弹出确认框，列明技能身份、精确版本、来源和目标范围；用户确认后才提交安装请求。取消或关闭确认框不发送写请求，焦点返回触发按钮。对话详情内的确认框保持在详情抽屉上方，关闭后保留原详情。DSH 自身要求的策略步骤仍由宿主处理。

如果安装时最新发布版本发生变化，仍安装详情已显示的精确版本；若该版本已撤销，则报错并提供刷新详情，不静默安装另一个版本。

## 6. 页面 P3：安装过程与结果

安装过程与结果遵循以下状态规则。

结果在详情页内展示，不用短暂 toast 作为唯一凭据；安装成功同时刷新“已安装”Tab。

### 6.1 安装过程

| 阶段 | 用户文案 | 行为 |
| --- | --- | --- |
| 接收与检查 | 正在检查安装条件… | 禁用重复安装与范围切换 |
| 下载 | 正在下载技能… | 没有字节证据不显示虚假百分比 |
| 校验 | 正在检查技能包… | 包错误保持目标不变 |
| 提交 | 正在安装… | 锁内重校验并写文件与记录 |
| 完成 | 已安装 | 分别展示文件与发现状态 |
| 失败 | 安装失败：原因 | 恢复信息和可用动作 |

现有核心尚无完整阶段事件，若不增加观察钩子，实现只显示可信的“正在安装…”而非伪造阶段。首版不提供取消安装按钮，避免用户以为已撤销实际提交。

返回目录或会话不取消已接收安装；Host 在当前进程中完成工作，Client 再次进入详情可查询结果。插件禁用或 Host 重启导致未确认完成时，下次通过文件和记录重新核验，不将未知状态自动重试为第二次写入。

### 6.2 成功与异常矩阵

| 状态 | 文案与动作 |
| --- | --- |
| 文件与记录已提交，DSH 已发现 | “已安装”“DSH 已发现”；返回会话或继续浏览 |
| 安装已完成但发现不可确认 | “已安装”“尚未确认 DSH 发现”；不声称已加载或执行 |
| 相同版本完整存在 | “已安装”；不重复下载覆盖 |
| 目标被其他版本/来源/文件占用 | “安装位置已有内容，本次未覆盖”；返回浏览或进入该目标的受保护升级预检，不提供强制按钮 |
| 源要求身份 | “当前内容无法匿名访问，首版暂不支持登录”；无登录引导 |
| 429 | “请求过于频繁，请稍后重试”；尊重可用的 Retry-After，不自动循环请求 |
| 网络/下载中断 | 保留技能、版本与目标，提供手动重试 |
| 不兼容 DSH | 展示具体原因，不重命名或重写技能包 |
| 部分恢复失败 | 明确“未完全恢复”，显示可复制诊断信息；不显示“已回滚” |

发现状态展示最近核验时间，以“上次核验时”描述确认结果。广场安装、升级及对话安装结果均提供“刷新发现状态”，只查询原操作，不重新安装、升级或调用模型。刷新期间显示核验中；资源变化或已卸载后可能转为未确认，原文件操作完成结果仍保留。完成操作不持续轮询，历史结果不承诺当前仍安装。

## 7. 页面 P4：已安装 Tab



此页回答“装了哪些、装在哪里、是否可更新、如何移除”。页面使用表格，字段为技能坐标、已安装版本、范围、本地状态、更新状态和操作。每行提供详情、检查更新、升级和卸载；可用性取决于身份、基线和计划检查。顶部提供本地关键词过滤和刷新，不自动检查全库更新。

默认显示当前来源在用户级与当前项目的可识别 SkillHub 安装，明确范围说明，不声称列出 DSH 全部技能。数据来自 inventory、目标 metadata 和文件存在性；没有访问远端也能显示本地记录，并可在本地预检通过后精确卸载。其他来源和无法确认身份的技能不混入。相同技能的两个目标分行展示。

“文件存在”不等于完整性校验通过或 DSH 已发现。清单残留、目录缺失、记录不一致须显示异常，不直接删除记录。读取部分失败时展示已读结果并说明不完整，不当作空列表。只有完整读取且零条目时显示“还没有从当前来源安装技能”，提供“浏览技能”。

打开已安装条目的详情绑定本地安装版本；远端不可达时仍保留坐标、版本、目标，显示远端详情不可用。同版本完整存在时显示已安装；其他版本占用时仅在独立升级预检通过后提供升级操作。返回恢复“已安装”Tab 的筛选与滚动位置。同一 Client 生命周期内，从已安装详情返回会话再进入 SkillHub，保留所选详情；在浏览与已安装之间切换保留本地筛选。该导航状态绑定会话及来源修订，两者任一变化均重置筛选和所选记录，不跨上下文恢复旧操作页面，也不将页面恢复当作写操作确认。浏览器刷新不承诺保留这些导航状态。

### 7.1 升级与卸载交互

- “检查更新”仅比较版本与本地状态，不改文件。检查结果显示时间，点击升级前重新生成不可变计划。
- “升级”在详情内展示旧版→新版、全部受影响安装位置和检查结果；确认后执行。现有 inventory 多目标共用版本，不能静默只升级其中一个；完整规则见操作分册。
- “卸载”针对选中一行，预检后弹窗显示坐标、版本、主机、范围和只读路径；用户确认后移除精确目标，不调用 Registry 删除接口。
- 本地修改、未知来源、缺失基线、Suite 共享、目标变化都要阻断；不提供强制覆盖/强制删除。
- 升级/卸载结果留在页面；刷新已安装条目和详情版本，发现/加载状态单独报告。

完整决策表、5 分钟计划时效、共享目标约束、文件事务与失败恢复见 [生命周期详细设计](lifecycle-design.md)。

### 7.2 升级计划：界面与动作关系

用户从已安装行进入详情中的升级计划，先看清版本与所有目标，再提交。

```mermaid
flowchart TB
  ROW[已安装行：当前版本与更新状态] --> CHECK[检查更新：只读查询]
  CHECK --> OPEN[可升级：打开详情内计划]
  subgraph PLAN[升级计划区域]
    ID[来源与完整坐标]
    VER[当前版本到目标精确版本]
    TARGETS[逐项列出主机、范围和只读路径]
    GUARDS[本地基线、共享所有权和目标集合检查]
    EXPIRE[计划截止时间]
    ACTIONS{用户操作}
    ID --> VER --> TARGETS --> GUARDS --> EXPIRE --> ACTIONS
  end
  OPEN --> ID
  ACTIONS -->|取消| KEEP[保留当前版本并收起计划]
  ACTIONS -->|确认升级| EXEC[执行并锁内复查]
  EXEC -->|成功| OK[显示新版本并刷新已安装列表]
  EXEC -->|失败| ERROR[显示实际恢复状态与可用后续动作]
```

生成计划后焦点进入取消按钮；计划阻断或无需升级时进入返回按钮。取消或返回后恢复到生成计划按钮，倒计时刷新不抢占焦点。计划阻断时不显示可点击的确认按钮；原因显示在目标清单旁。计划生成后如果用户切换来源或当前项目，页面保留失败原因并要求重新检查，不静默更新旧计划的目标。取消只取消未提交计划；已进入提交阶段没有“取消”操作。

### 7.3 卸载确认：字段和分支

```mermaid
flowchart TB
  ROW[已安装行：卸载] --> PRE[预检唯一目标]
  PRE -->|不可信或有本地修改| BLOCK[保留文件和记录，显示阻断原因]
  PRE -->|可信| DIALOG
  subgraph DIALOG[卸载确认弹窗]
    NAME[完整坐标与已装版本]
    SCOPE[主机、安装范围、只读目标路径]
    IMPACT[仅移除此位置，不删除远端与其他副本]
    RUNNING[说明不强制终止当前运行任务]
    CHOICE{取消或确认卸载}
    NAME --> SCOPE --> IMPACT --> RUNNING --> CHOICE
  end
  CHOICE -->|取消，默认焦点| BACK[关闭弹窗，原行不变]
  CHOICE -->|确认卸载| EXEC[执行精确目标事务]
  EXEC -->|完成| DONE[移除原行并显示结果]
  EXEC -->|有残留| WARNING[逻辑卸载完成，保留清理告警]
  EXEC -->|失败或待恢复| FAILED[显示失败，禁止冲突写操作]
```

目录已明确不存在时，弹窗标题与主按钮改为“清理失效记录”，不使用“确认卸载”暗示有文件被删除。确认按钮带明确动作名，不使用含糊的“确定”。关闭弹窗恢复焦点到触发行；成功后原行消失则移到列表标题，并播报实际结果。

## 9. 视觉、响应式与可访问性

使用 shadcn/ui 的 Radix 组件源码，适配为插件局部样式；页面与文字继承 DSH 深浅主题，局部主操作、选中标签及焦点统一使用强调色，头像使用稳定的柔和多色，辅助按钮描边。排序、安装范围及其他下拉统一使用 Select，支持键盘选择，浮层保持在插件样式边界内。复用宿主 React/React DOM，不加载第二套运行时，不引入全局 CSS reset。弹窗内容与遮罩也必须处于插件样式边界，错误使用文字与图标双重表达。早期配图用于说明流程，具体视觉以本节紧凑头像卡片规范为准。

以主内容区可用宽度布局：宽屏三列卡片、中等宽度两列、窄屏一列；具体断点在实际宿主验证后确定。详情有足够空间时正文与安装信息两列，否则单列，不占用宿主右侧会话面板。

卡片使用一个明确的可访问打开动作，避免按钮嵌套；详情打开聚焦标题，返回后聚焦原卡片；搜索结果与安装结果通过温和的状态区域播报。长坐标允许换行或复制，不截断唯一身份。中文与英文均需验证长文本。

## 13. 已确认视觉基线与还原验收

2026-10-16 确认 refined-v2 交互原型；第 3、4、5、9 节为正式界面约定。原型截图及离线 HTML 归档于仓库外 `dsh-refined-v2-20261016`，不随插件发布。

- 实现必须还原浏览、已安装、详情、版本、评论各页，不能仅替换目录卡片。
- 评论使用作者首字符头像、公开显示名、星级、可读日期及正文；评分与评论属于整个技能，接口未返回的“使用版本”、总评分等字段不得从示例补写。只有一条评论、空结果、未开放、加载失败分别检查。

- 详情内容卡的 Tab 悬停保持透明底色，以强调色文字反馈，选中状态保留下划线；键盘焦点保留清晰轮廓。目录分段标签沿用其独立样式。
- 内容卡 Tab 选中指示与当前正文同步；空状态、错误、加载和短内容也保持容器布局。分页保持位于内容卡底部。
- 关闭 X 与返回目录的语义、来源信息可访问性、Select 键盘和嵌套弹层焦点必须在真实 DSH 中验收。
- 原型的分类、名称排序和演示状态控制不是生产功能；正式目录仍仅提供现有接口支持的排序与过滤。审核匿名访问边界保持第 5.3 节约定。
- 原型模拟 DSH 外壳，不将模拟侧栏复制到插件；最终视觉与行为以真实宿主的深浅主题、窄屏和参考插件共存验证为准。


## 14. 版本安装与状态信息层级

### 14.1 选择版本

广场版本行提供“查看此版本”入口，可下载版本才可选择。选择后重新读取精确版本的详情、说明与安装凭据，右侧明确显示所选版本；读取期间或失败时不保留可提交的旧版本安装按钮。点击安装后仍需确认技能、版本、来源与范围。版本可见不代表当前仍可下载，失败如实反馈，不静默换为最新版。

目标范围未安装时可安装所选发布版本；已经存在其他版本时，不以指定版本安装覆盖现有内容。升级继续使用既有预检流程，本轮不引入降级。已安装详情始终对应本地版本。对话详情的搜索引用和展示确认绑定原版本，选择其他版本通过“前往广场选择版本”完成，不复用原对话引用。

### 14.2 安装区域

主区域默认展示所选版本、安装范围、当前状态和一个主要操作。状态涵盖核验中、未安装、已安装、其他版本占用、安装中、安装失败和状态未知。当前状态来自独立的本地安装记录读取，不能仅根据历史安装成功判定。

成功后刷新当前记录，简洁展示安装版本及发现状态。原操作 ID、完整核验时间、来源快照、诊断和原操作回执收进可展开的“操作详情”；原记录仍保留并可查询。失败、恢复待处理、结果未知、库存读取不完整、文件异常和操作告警保持可见。折叠不取消 Host 操作，不改变恢复或幂等语义。

### 14.3 已安装页

技能卡片突出名称、坐标、已安装版本、范围和简洁状态；详情、检查更新、卸载为明确动作，更新状态不与文件状态混写。卡片使用清晰描边、独立底色和轻阴影，在深浅主题下都应能区分于页面背景。

历史升级与卸载收进操作记录区。只有已确认完成且无告警的结果默认折叠；进行中、失败、恢复待处理与状态未知项默认展开，保留查询和恢复入口。当前安装列表与历史操作分开表达，不把旧操作结果冒充当前安装状态。


## 15. 标签筛选与已安装详情侧栏

目录搜索区下方展示公开标签单选按钮，“全部”表示无标签过滤。标签来自实例 GET `/api/web/labels`，使用服务端 displayName 和顺序，不能把版本 tags 或示例分类当作标签。字号 12px、常规高度 28px，标签多时换行；使用可访问选中状态与清晰焦点。

标签选择与关键词、排序共同参与服务器分页查询。新选择从第 0 页开始，详情返回保留标签和已加载结果；来源变化不能沿用旧来源的选择。标签目录不可用不阻塞普通搜索，404/405 隐藏标签入口，其他失败提供独立重试。带标签查询失败不得展示无过滤结果；已选标签仍应可以清除。

已安装详情正文仅承担技能内容。重新读取详情、检查更新、版本状态及检查时间集中在右侧“版本与更新”卡片；辅助文字 12px，时间格式可读，保留原始时间语义，不显示裸 ISO 串。窄屏侧栏自然移至正文下方；升级资格、恢复状态、查询行为及焦点管理保持不变。


## 16. 对话安装结果与导航标识

对话安装成功结果使用紧凑卡片：技能头像与名称、完整坐标、右侧状态标识、版本/范围短行及一句核心结果。辅助动作收纳到“安装记录”，避免安装完成后仍展开多个查询按钮、原始时间与操作标识。技能无真实图片时继续使用稳定首字符头像，不虚构名称或评分。

安装记录默认折叠，用户可自主展开和收起；不会因历史记录无法核验而自动铺开诊断。主区只保留一句结果、一个“核验状态”按钮及适用时的“在已安装中查看”入口。核验动作刷新原操作及允许读取的当前库存，发现状态、核验时间、来源和操作详情收进记录。库存缺失、版本变化、数据不完整或无法核验时，主区明确标记历史结果和当前问题；只有当前完整库存中原范围、版本与文件匹配，才展示当前核验成功。失败、恢复待核验与查询失败保留必要警告和核验入口，不依赖展开才能发现异常。

侧栏入口为“技能中心”，图标采用三个圆角模块与组合标记的 SVG，使用 currentColor 适配宿主深浅主题；不使用字母 S 或 emoji。内部页面继续展示 SkillHub 品牌，插件标识及注册 ID 保持不变。


## 17. 保留布局的加载状态

首次进入技能中心，来源配置读取期间保留顶部品牌与关闭入口，展示禁用的目录Tab、搜索和排序框架及6张卡片骨架；不以单行“正在读取来源”替代主体。`getContext`读取Host配置，不据此提示远端Registry缓慢。

目录首次加载复用实际卡片比例的骨架；已有数据后台刷新保持原卡片，加载更多只禁用对应按钮并保留已加载结果。详情读取保留技能身份、正文区域和安装侧栏占位，未取得核验详情前不提供安装操作。来源/接口失败显示具体错误与可用重试，骨架不表示成功或不存在。

Skeleton沿用局部shadcn组件风格和DSH主题变量，不引入新依赖或全局样式。加载区域提供aria-busy及单一可读状态，装饰骨架对辅助技术隐藏；动画遵循prefers-reduced-motion，窄屏维持真实布局的断点。

## 18. 插件连接配置页

配置页沿用DSH主题与现有shadcn组件，以“技能来源”和“详情标签”两张卡片组织。来源卡提供Registry地址输入及简短说明，已配置标识仅表示已保存地址，不代表连接测试成功。详情标签卡按版本、安全审核、评论逐行配置，沿用自动检测、显示、隐藏三种模式。

页尾保留主操作“保存配置”和次操作“重置修改”。重置只还原当前表单快照，不宣称重新请求Host。加载使用骨架，保存期间禁用编辑；只读、URL无效、保存失败和revision冲突明确反馈。成功反馈不依赖颜色；窄屏收紧卡片内边距与选择器宽度，操作栏允许换行，深浅主题均使用宿主语义色。

技能市场标签来自来源的`GET /api/web/labels`，选中后由技能列表接口的`label`参数筛选，不在插件内预置业务标签。当前隔离预览的标签为测试服务示例数据，不代表正式市场。

### 18.1 测试来源连接

来源输入旁增加小号“测试连接”按钮，读取当前输入的草稿地址，不要求先保存，也不修改来源配置或已安装记录。测试从DSH Host发起匿名只读请求，验证公开技能目录接口；旧来源可使用既有基础搜索回退。结果只展示通过/失败、公开目录或基础搜索可用、请求耗时及必要错误说明，不宣称安装、审核、评论或模型调用均已可用。测试通过不等于配置已保存。

测试期间禁用重复提交，整个测试含回退最多10秒。地址修改、重置或组件卸载取消旧测试，旧地址结果不得覆盖新草稿。空地址不发请求，非法地址给出明确提示。测试、保存与重置按钮统一使用小号规格，保持清晰焦点与禁用状态。
