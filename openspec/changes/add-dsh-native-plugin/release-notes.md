# SkillHub DSH 原生插件 0.1.0 发布候选说明

## 版本与交付状态

当前为 `@astron-team/skillhub-dsh@0.1.0` 发布候选，已设置 `private: false` 和公开发布权限，尚未发布到 npm。候选可用于本地安装和验收，不代表已正式发布或全平台支持。

目标环境固定 DSH `0.2.0-rc.2`、Cordis `4.0.4`、Node `>=24.2.0 <25`。当前已验证 Linux Host、真实浏览器页面与交互，以及 Windows 浏览器访问 Host；界面已完成人工 review。Windows 浏览器通过不代表 Windows 原生 Host 全部文件事务通过；macOS 真实 Host/客户端、其他 DSH 发行版和 SaaS 实例仍需独立验收。

## 功能

- **原生技能中心**：侧栏使用专用 SVG 入口；浏览和已安装视图独立。紧凑头像卡支持首字回退、实际统计、分页、排序和来源提供的标签筛选。
- **详情与版本**：文档、版本、安全审核和评论按 `auto/show/hide` 展示；评论只读。可查看并安装指定的可下载版本，重新获取精确凭据，不绕过已有版本的冲突保护。
- **对话交互**：搜索结果使用紧凑卡片和明确详情按钮，详情抽屉沿用固定版本与来源校验。搜索本身不安装；用户明确选择并要求安装时，可直接核验原搜索快照后执行。
- **安装结果**：主区呈现简洁结果和查看已安装入口，展开安装记录可核验原操作与当前库存；历史完成、当前记录变化、发现状态和模型执行保持区分。
- **本地管理**：用户/可信项目安装、主动检查更新、完整目标集合升级、单位置卸载及失效记录清理。不存在自动更新、技能降级或强制覆盖。
- **配置与主题**：来源和详情标签使用 shadcn/Radix 组件；支持保存、重置修改、只读与 revision 冲突。“测试连接”读取当前草稿地址而不保存，显示公开目录或基础搜索可读性及耗时，10 秒超时可重试，改地址清除旧结果；不据此宣称下载和所有模块可用。界面跟随 DSH 深浅主题，提供窄屏布局、骨架加载及减少动画设置。
- **恢复与保护**：复用受保护的文件事务、inventory 和操作日志。响应丢失查询原请求，重启不自动重放未完成操作。升级、卸载与恢复仍核验来源、会话和目标归属。

插件内置共享安装核心，不要求另装 SkillHub CLI，不读取 CLI 登录凭证。浏览器使用宿主 React/React DOM；样式和交互组件限定于插件范围。

## 稳定性修复

- 安装受理后、写入开始前进程中断时，恢复可核实无写入状态并安全结束原请求，避免无效待处理操作持续阻止升级和卸载；未知或损坏日志仍拒绝自动处理。
- 已安装条目引用按范围和条目保持稳定；超过 400 条或重复刷新时，不再因缓存淘汰使刚展示的条目失效。实际操作仍重新核验可信上下文、记录和文件归属。
- 项目范围不可用时，正常用户范围仍可安装；当前选中范围存在不可核验记录时保留保护。
- 重复安装已存在的同版本后，以只读完整性核验确认 DSH 发现状态，不要求生成一次新的文件写入提交。

## 接口与配置

配置字段为 `registryUrl`、`detailTabs.versions`、`detailTabs.securityAudit`、`detailTabs.reviews`。地址禁止包含凭证、查询参数或片段；默认留空，不预设公开实例；空值表示未配置。配置页“已配置”仅指保存状态，不表示连通成功。

复用匿名目录、标签、搜索、resolve、元信息、固定版本说明/下载、版本及评论接口，没有新增服务端文件安装任务。安全审核保留匿名访问限制，不将无法读取显示为通过。SaaS 需同步实际路径、字段、公开策略和测试，不能用开源实例验收代替 SaaS 验收。详见 [Registry 契约](registry-api-contract.md) 和 [接口设计](interface-design.md)。

## 安装、更新与维护

正式发布后可通过 `dsh plugin --profile skillhub-test add @astron-team/skillhub-dsh@0.1.0 --ignore-scripts` 安装到已有 Web Profile。发布前从源码执行 `bun run check` 后生成 `.tgz`，使用固定版本 DSH 的 `plugin ... add` 安装。具体准备、命令、配置和测试流程见 [中文指南](../../../plugins/dsh/README.md)、[英文指南](../../../plugins/dsh/README.en.md) 及 [发布指南](release-guide.md)。

更新或回退前保留原包和校验值、停止新操作并处理待恢复事务，然后停止 Host、安装兼容包并重新启动。浏览器旧资源可强制刷新；这不能代替 Host 依赖重载。禁用或移除包不会卸载技能，不应删除技能目录、inventory 或操作日志。

## 验证与限制

构建、类型检查、lint、单元/契约/打包测试均有对应检查入口；CI 包含三平台、两组 Node 版本和隔离 Web Profile Host 冒烟。实际结果须对应最终候选校验值，不以 CI 配置存在证明平台通过。浏览器验收覆盖配置、目录、详情、对话卡片、安装管理、主题、窄屏及加载/错误状态；人工 review 不替代自动化和文件事务验证。

明确限制：

1. 当前 UI 为中文，英文指南不代表英文 UI。
2. 真实模型行为取决于模型和会话；安装成功、DSH 发现和模型执行分别验证。资源路径成功个例不保证所有技能的相对路径解析。
3. 官方 RC.2 在同端口 Host 重启后可能使原标签页空白，不能承诺无缝重连；使用有效入口重新进入并查询原操作。
4. 开发候选之间的替换与回退验证，不等于跨正式版本日志迁移兼容。未知格式不能通过删除日志绕过。
5. 注册、页面或工具共存测试不证明其他插件全部业务及模型选工具行为均兼容。

兼容范围以 [兼容设计](compatibility-design.md) 为准，行为门禁以 [验收标准](acceptance.md) 为准。

## 正式发布前门禁

- 确定正式版本、最终候选校验值和支持平台；未验证的平台、DSH 或 SaaS 组合不得声明支持。
- 验证候选包在干净目标 Profile 中安装、读取来源、安装测试技能及保留原数据的维护流程。
- 确认可发布 manifest、`dsh-v<version>` tag、npm 身份和受保护发布环境审批；`0.1.0` manifest 可发布，但仍需完成最终候选验收与审批。
- 获批发布后，从 npm 下载实际包，对比完整性并执行发布后安装检查。

插件、开源服务和 SaaS 独立发布；本说明不表示已创建 tag、上传 npm 或部署服务。
