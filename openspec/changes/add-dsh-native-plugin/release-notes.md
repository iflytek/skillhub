# SkillHub DSH 原生插件：开发候选变更说明

## 版本与适用范围

当前候选为 `@astron-team/skillhub-dsh@0.0.0-m0`，保持 `private: true`，未发布到 npm。本文描述可供验收的开发版本，不代表已获发布批准。

研发和验收固定 DSH `0.2.0-rc.2`、Cordis `4.0.4`，Node 范围为 `>=24.2.0 <25`。DSH 官方依赖使用精确版本，不声明兼容其他 RC、Alpha 或未来发行版。Linux 和 Windows 已有分项实机证据；完整平台 CI 尚未执行，macOS 验证延后，独立远程 Host 尚未验证。

## 本次交付

- DSH 原生侧栏技能广场，包含浏览和已安装两个入口；详情使用独立子页面，返回保留列表上下文。
- 详情、版本、安全审核、评论支持 `auto/show/hide`。读取遵守 Registry 的匿名策略，评论只读，不提供登录和权限管理。
- 对话内搜索结果、详情抽屉与安装卡片。搜索条目整卡可点击并支持键盘操作；打开技能广场保留搜索词。关闭抽屉不发起安装。
- 显式安装到可信用户或项目范围，完整保留技能资源；安装、升级和卸载共用受保护文件事务、清单与操作日志。
- 已安装管理提供主动检查更新、确认升级、单目标卸载和独立确认的失效记录清理。对话工具首期不支持升级或卸载。
- 历史安装结果与当前安装记录分开展示。受理后的安装不因停止对话或关闭浏览器而撤销；重开会话查询原操作，不重复安装。

## 安装与维护

使用开发 tarball 和专用 DSH Profile，按[中文指南](../../../plugins/dsh/README.md)或[英文指南](../../../plugins/dsh/README.en.md)完成构建、安装、更新、禁用及回退。插件内已包含安装核心，不要求另装 SkillHub CLI，也不读取 CLI 登录凭证。

配置项为 `registryUrl` 和 `detailTabs`。Registry 地址不得包含凭证、查询参数或片段；地址变更使尚未受理的旧引用失效。Host 重启后，历史搜索需要显式“重新查看详情”才能获得新引用；此操作不授权安装。

文件操作出现不确定结果时，保留操作 ID，先查询原请求，再按界面执行“核验并恢复”。禁用或替换插件不会删除已安装技能。不得通过删除日志、清单或未知目录绕过恢复检查；插件回退与技能降级是不同操作。

## Registry 接口与服务端同步

插件复用现有匿名列表、搜索、详情、版本、文档和下载接口，本次没有新增业务路由或放开匿名审核权限。服务端补充 OpenAPI 响应说明并同步生成类型，实际变更见 [Registry 契约与 SaaS 同步清单](registry-api-contract.md)。

真实开源测试 Registry 已有匿名契约、原生安装及技能资源使用证据；SaaS 尚未同步验收，不能以开源结果代替 SaaS 支持声明。可选模块不可用时按配置隐藏或显示明确错误，不伪装为空集合。

## 验收结果与已知限制

当前构建、类型检查、lint 和 198 项插件测试通过。对话搜索、明确安装、歧义澄清、资源使用、官方 Stop、浏览器断线重开、历史详情和失效记录已有对应证据。整条搜索候选在实际 DSH 中通过点击、键盘、焦点恢复和 390px 内容换行验证。

这些结果不构成所有模型行为的保证。真实 Registry 技能的成功资源使用用例明确提供了资源绝对路径；模型自动解析相对路径曾失败。文件安装成功、DSH 发现确认和模型实际使用是不同状态。当前 UI 为中文，英文指南不代表提供英文 UI。

本地候选包含 60 个文件，运行产物与当前构建一致；实际打包 manifest 通过候选身份校验，并确认私有包发布请求、CLI tag 和分支上下文均被拒绝。文件清单和校验结果见[候选包审计报告](../../../docs/research/dsh-native-plugin-2026-10-12/candidate-package-audit-result.json)，完整证据见[验证记录](verification.md)。

## 发布前未完成项

以下事项仍是独立门禁，不因本说明已编写而视为通过：

1. 完成剩余 Linux/Windows 平台与独立远程单用户 Host 验收，核验最终候选的文件落点和上下文归属。
2. 执行远端 CI，固定正式支持基线，完成最终候选包与回退、日志兼容证据核对。
3. 确认正式版本和可发布 manifest，核验发布环境及审批规则；创建 tag、推送和 npm 发布均需另行授权。
4. 发布获批后，从 npm 下载实际包，核对完整性并在干净 DSH 环境完成安装、浏览和技能安装验收。

发布操作顺序见[发布指南](release-guide.md)。当前候选可用于继续本地验收，不可作为已发布版本交付。
