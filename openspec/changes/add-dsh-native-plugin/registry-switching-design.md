# 多来源保存与当前来源更新检查（本地实现与验证完成）

本增量由 2026-11-02 需求讨论提出，已实现并完成本地自动化及真实 Host／浏览器验证；版本发布另行安排。本文归属既有 DSH OpenSpec，不创建另一套独立产品协议。

## 已确认范围

- 保存多个具名 Registry，任一时刻仅选一个当前市场来源。首期不聚合多个市场，不新增登录或私有访问能力。
- 切换市场不删除、移动、停用既有技能，不改写安装的来源身份；已安装技能保留使用及管理能力。
- 更新检查、可更新筛选和可执行升级入口仅适用于当前来源。其他来源未检查不等于已是最新，不计入本轮成功或失败数量。
- 切换后取消旧来源只读更新检查，丢弃迟到响应并隐藏旧更新提示。切回后重新检查，旧结果不能直接成为升级授权。
- 绝不以新来源同名技能替换旧来源安装；新安装遇目标冲突沿用现有保护。
- 删除保存的来源只删除连接配置，不删除其安装。变更URL是连接目标变化，不能自动迁移既有安装归属。
- 已提交的文件事务遵守现有事务/恢复机制，切换来源不等于回滚或取消已接受的写入；旧确认引用必须失效。
- 保持共享库存v2、原有安装记录及CLI兼容，不能为了多来源修改历史库存来源。
- 升级前查看变化、场景助手、会话加载面板、套件接入均不在本增量范围。

## 当前实现接缝（本地 origin/main 12f850c5a）

- `plugins/dsh/src/host/config.ts`：仅 registryUrl 与 detailTabs；地址缺省为现有默认，显式空串断连。
- `plugins/dsh/src/client/config-page.tsx`：通过宿主配置表单写入 registryUrl；配置可能只读。
- `plugins/dsh/src/host/index.ts`：Host 服务持有单一 registry/sourceRevision；重配导致来源上下文变化。
- `listInstalledForAgent` 传当前 registryUrl 到本地运行时；来源绑定引用贯穿可用性和管理方法。因此“保留其他来源安装管理”必须核对其投影和授权，不能只增加地址下拉框。

## 共享作用域与交互

用户已确认同一 DSH Profile／插件实例共享当前来源，不做每会话独立选择。

- 技能中心顶部不展示来源选择器。来源选择及具名来源的新增、编辑、删除统一放在现有设置页的“技能来源”中；选择后保存生效，不新增管理中心。
- 浏览页只展示当前市场。已安装页展示全部可信受管安装，仍以使用技能为主要操作；仅其他来源安装显示一个来源标识，管理在详情页二级区域进行。
- 其他来源详情仅展示可信本地内容和本地管理，不向当前市场请求同名详情，也不提供错误的官方链接、远程版本或升级按钮。
- 当前来源更新筛选和汇总只统计当前来源。没有匹配安装时显示“当前来源暂无可检查的技能”。
- 来源只读或配置服务不可用时禁用修改；保存冲突提示重新读取，不覆盖另一个页面的选择。
- 删除当前来源同时断开连接，不自动切往别处。断开后远程浏览/检查不可用，本地受管技能仍可使用、诊断、启停和卸载。

## 配置与兼容设计

新增可选 `savedRegistries: Array<{ name: string; url: string }>`，保留 `registryUrl` 为唯一当前地址，不新增 activeId 双重状态。列表缺省为空，旧自定义地址作为当前项可见，首次读取不强制回写。省略 registryUrl 的官方默认和显式空串断开语义保持不变。

地址验证及来源比较复用现有逻辑，不扩大 URL 等价规则；相同来源去重，名称只用于展示，不能成为库存归属。地址不接受凭证、查询串和片段。添加或改名不自动切换；修改当前条目的 URL 时将列表和当前地址原子保存，并按来源切换处理。

复用 Host configForms 的 revision CAS 和订阅：设置页来源选择写入 registryUrl 草稿并在保存时生效；删除当前项等复合编辑原子提交。其他页面通过配置通知和 Host sourceRevision 丢弃旧读取及确认。无额外数据库、localStorage 或库存迁移。

## 全来源本地管理与更新隔离

- `cli/src/integrations/installed-projection.ts:45` 当前过滤非当前来源；保留现有当前来源投影，新增明确的全部受管来源读取，共用库存/根目录校验。
- 投影携带可信库存 registry。Host 的 itemKey、locationKey、卡片分组、缓存和导航均使用 registry + namespace + slug（位置键另含 scope/path），不能将两源同名技能合并。
- `plugins/dsh/src/host/index.ts` 的 readInstalledItem、本地 use/diagnose/toggle/remove 及回执使用重读 item 的真实来源；保持根目录、指纹、修改检测、共享目标、sandbox、库存 CAS 与 sourceRevision 校验。
- getInstalledDetail 对非当前来源采用本地路径；远程详情仅允许当前来源。显式断开也不短路本地能力。
- 单项 checkUpdate/prepareUpgrade 在 resolve 前由 Host 拒绝来源不符；批量 scan 保持当前来源快照。UI 隐藏按钮不是授权边界。
- 切换时清理读取缓存、失效未提交计划、终止旧检查；无法终止的请求通过 revision 丢弃结果。已受理事务保留原始身份和幂等键，继续可查询结果。

## 实施顺序及风险

1. 兼容配置与共享切换，覆盖只读、并发保存和重启。
2. 全来源可信投影和来源身份贯穿本地管理，保持 CLI 默认查询语义及库存 v2。
3. 后端当前来源更新限制、扫描统计及竞态处理。
4. 页面来源选择、旧来源本地详情及精简状态展示。
5. 回归、真实 Host/浏览器验收及文档；分别记录自动测试与人工预览证据。

重点风险是跨源同名误分组、详情串源、断开时本地能力被旧逻辑短路，以及切换与已受理事务竞态。均需专项用例；不通过放宽既有确认或文件保护解决。回退不迁移库存，新字段可由旧版本忽略，原 registryUrl 仍可读取；旧插件仍按原行为只展示当前来源。

## 验收标准

1. A安装技能后切至B，A技能文件/启停状态不变，已安装仍可识别及使用；管理不得将来源冒认为B。
2. B下检查更新只访问B，不产生A远程请求；B同名新版不触发A安装的更新提示。
3. A慢请求与切B竞态：响应晚到不污染B结果；原更新确认不可执行。
4. B下其他来源安装不计入已最新、检查失败、可更新数量；切回A发起新检查。
5. A不可用与B不可用独立处理；删除A连接后安装保留。
6. 同技能双范围安装分别判断版本，来源与安装范围两个维度不可混淆。
7. 升级已提交时切换来源，真实文件事务最终结果仍可追踪，不重复提交、不伪造取消。
8. 旧registryUrl配置、显式空串、只读配置、重启、多个页面均有明确兼容行为。

9. 显式断开或删除当前连接后，本地管理仍可用且无远程请求；两源同名技能不合并，旧来源详情不串源。
10. 真实 DSH 双页面切换和重启保持选择；浏览器验证紧凑布局、按钮行为及错误反馈，提供可访问的本地预览。


## 本地验证结果

- 构建、类型检查、lint 与 OpenSpec 严格校验通过；DSH 全量 677 项通过，最终配置序列化修复后补跑配置 10 项与安装 UI 8 项专项。
- CLI 类型检查、lint、构建通过；全量首轮受环境库存和并发超时干扰，六个失败文件以隔离 HOME、原时限逐一复验通过，保留首次失败记录。
- 两个支持的 Host（0.2.0-rc.2、0.2.1-rc.2）均运行真实双来源文件事务与浏览器流程。慢响应切换、已受理升级继续、幂等、跨页配置 CAS、断开管理、同名分组通过。
- 新版同 Profile 真实进程重启后，保存的来源名称及当前选择保留；重启不重复运行配置/安装观察器。
- 新增可复现入口见 `plugins/dsh/test/integration/README.md`“多来源切换与本地安装管理”。Registry 为本地 HTTP 夹具；未调用模型，不构成 SaaS、跨操作系统或冷安装验收。
- 真实浏览器曾发现配置 schema 回调无法还原，已改为可序列化结构并新增跨进程序列化回归；不以 mock ConfigForm 通过替代 Host 兼容性。

## 真实模型补充验收

真实模型首轮把来源地址误用为上下文引用，Host 正确拒绝但对话检查失败。补充参数字段说明，明确当前来源仅代表检查资格，区分只读检查和写入确认，并为安装引用过期与操作回执过期分别提供恢复指引。该指引不放松 Host 校验，不承诺强制约束模型措辞。

修复后真实模型新会话三轮完成查询、切源后当前来源检查，以及按钮操作后重新查询；旧失败会话经一次新列表读取恢复。真实模型调用使用隔离的本地 Registry 数据，未执行升级/卸载，不代表生产 SaaS 全链路验收。旧历史仍有措辞偏差，新回复也可能冗长，原始失败记录保留。

## 设置页信息层级

设置页采用“技能来源 / 页面显示”两个胶囊标签，复用宿主控件与主题；Tab仅切换内容，不保存配置、不丢弃草稿，也不触发连接测试。每个标签用一张内容卡片包裹。来源页以同一列表选择和管理来源，行内显示名称与地址，新增或编辑时才展开字段；不重复显示当前地址输入及保存来源列表。旧配置中未保存到列表的当前来源仍可见可管理。测试连接和断开操作作用于草稿，保存前不切换宿主；页面显示集中版本、审核与评论选项。共用明确的保存/重置区域，保存跨Tab草稿并保持原配置revision CAS。只读、加载、保存中、冲突与连接测试失败仍需可见，隐藏Tab中的校验错误应能引导定位。窄屏不出现横向溢出，Tab支持键盘操作。
