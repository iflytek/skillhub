# 已安装技能统一检查更新

## 范围
用户主动检查当前来源、当前工作区可见的受管理安装。无进入页面自动扫描、后台轮询、批量执行、自动覆盖或新增Registry/SaaS协议。日常仍按技能聚合；实际检查/更新以精确itemKey为单位。

## 交互
已安装页提供检查更新与进度n/m；结果渐进呈现，不逐项弹通知，不阻断浏览。汇总可更新技能数与检查失败项，支持全部/可更新/检查失败筛选和失败重试，关键词可叠加。已最新无卡片冗余文字；卡片右上角最多展示两个状态标签：安装状态仅在已停用或待核验时展示；更新标签按检查失败、需处理、可更新优先级展示一项，单位置可更新保留目标版本，多位置统一显示“可更新”，其余细节进入详情查看。正常已安装不重复标记。卡片头部组合头像、名称、命名空间与右侧状态；无状态时不预留独立标签行。保持紧凑间距和同排按钮对齐，窄屏下状态与长名称不能重叠。点击卡片（支持键盘）进入现有详情右侧，移除重复的管理安装、详情与查看更新按钮；仅可用技能保留使用技能主动作，点击使用不触发详情跳转。返回列表恢复焦点、滚动和有效筛选。位置结果独立：同技能只计一个可更新技能，但不同位置版本与确认分开。blocked显示需处理，不算可执行更新；unavailable/错误算检查失败，不伪报已最新。

## 技术边界
统一检查使用DSH私有只读检查轮次；保留原单项checkUpdate和精确位置prepareUpgrade事务，不另造批量写入API。客户端有界并发只读检查；重入禁用，取消/离开/切来源/会话/工作区时中止在途并丢弃迟到结果。结果仅适用于同一来源会话及同一安装引用。库存变更、更新/卸载/启停导致旧itemKey失效时清除对应结果。详情返回保留仍有效结果与筛选；详情更新执行始终重新核验，不把检查结果当授权。错误/空库存/不完整库存明确表达，不能全局显示全部已最新。

## 验收
覆盖空安装、单份、同技能多位置不同结果、全部最新、可升级、本地修改blocked、网络失败重试、混合结果、扫描中切换与重复点击、迟到结果、安装变化后结果失效。确认没有任何扫描触发写操作。真实DSH检查进度与汇总筛选、详情返回、逐位置升级确认取消、深浅色与窄屏，原安装不变；本轮不需模型调用。

## 工具栏展示约定
搜索和检查操作在同一响应式工具栏，筛选采用与页面一致的紧凑按钮组（全部/可更新/检查失败），不使用平台原生下拉菜单。筛选和单行摘要放在第二行；未检查仅显示技能数量，运行中明确进度，完成后仅显示有意义的更新与失败计数，零失败隐藏。不重复显示列表数量段落；窄屏允许自然换行，保留可见焦点和选中语义。

## 规模与资源边界
每轮仅建立一次可信库存快照并索引目标，逐项只核验对应目标与库存文件版本；不能将全量库存读取/解析或全安装目录核验放入逐项循环。库存文件变更使本轮失效，重新检查建立新快照。快照建立前后需核验文件版本，避免跨变更读取。每轮同来源同技能共用远端resolve；不同安装位置仍独立判断版本结果。失败重试新建轮次，不永久缓存失败或版本。

轮次引用只由Host生成并绑定真实会话/工作区/来源/文件服务/运行时，客户端不提供路径。数量、生命周期和并发有界，结束、取消、过期和销毁释放资源；单个位置等待取消不误杀同技能其他位置共享请求。旧轮次结果不得流入新上下文，检查快照不能作为写入授权。

性能验收覆盖10/100/500处安装，分别记录库存读取、目标核验、远端请求次数和耗时；以读取次数和工作量接近线性为主要回归断言，不使用机器相关固定耗时阈值。真实DSH验证新私有协议、渐进结果、取消和原逐项更新确认。

## 已安装卡片的信息与展示来源
已安装卡片采用紧凑横向布局：左侧头像，中间真实标题、一行简介及弱化的安装版本/命名空间，右侧必要状态与操作。桌面两列、窄屏一列，极窄卡片操作自然换行，不挤压标题。安装位置版本不同时展示多版本摘要，不把最新市场版本冒充本地版本。保留使用技能主操作与整卡详情入口；更多菜单仅提供管理安装和检查更新。管理安装进入既有详情右侧，检查更新复用只读轮次并限定当前技能的精确安装引用，多位置分别检查，不执行更新。菜单与使用操作不冒泡打开详情，关闭菜单恢复触发器焦点，进入详情后返回恢复卡片焦点。日常卡片不展示启停、卸载或检查可用性。最多两个状态标签，可更新使用柔和蓝色、已停用中性灰、失败/需处理琥珀色，明暗主题均可读且不只靠颜色表达。窄卡状态自然换行，不挤掉标题。无摘要时展示简短缺省，不编造用途。

列表展示信息从可信受管理安装位置的 SKILL.md 或 SKILL.md.disabled 读取，返回可选 displayName/summary。固定文件、普通文件、有界读取、拒绝符号链接和异常路径；YAML解析仅抽取有界字符串，不执行标签或内容。失败仅省略展示字段，不改变安装状态、完整性判定或来源。展示字段不进入安装引用、授权和更新快照。只在列表读取，保持一次库存读取，无逐卡网络详情请求、全目录摘要哈希或影响检查更新的快照热路径；会话、来源、根目录变化仍在返回前核验。
