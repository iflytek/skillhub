## Context

当前 `main` 已提供 Organization 成员与角色管理、连接摘要以及 V62 的连接和 revision 表。总体设计位于 [企业身份设计](../enterprise-identity-platform/design.md)。历史草稿 #894 是实现参考，本次从当前 `main` 按职责提取。

## Design

- 组织管理页面复用当前权限投影；服务端对每项操作检查目标组织、有效成员关系和对应角色。授权规则以治理规范为准。
- 同一连接详情页按权限分别显示配置和密钥操作。密钥管理员确认 issuer、client ID 和草稿版本后录入密钥；服务端拒绝过期版本，写入仅创建配置相同的新 revision。issuer 或 client ID 改变时，新版本需要重新录入密钥、探测及激活。
- OIDC Adapter 校验并保存类型化配置。连接测试限定于配置元数据和 JWKS；使用有界的出站请求策略。客户端凭证和真实用户登录由 R1-C 验收。
- revision 绑定配置及密钥版本。探测后再次校验目标版本，确保旧测试结果不能激活变更后的草稿。激活切换及审计在同一事务提交。
- 控制面区分最新草稿与当前或上次生效版本。恢复使用独立操作，在同一事务内校验组织权限、暂停状态和用户确认的生效版本，保留草稿、密钥和探测结果。
- 默认关闭连接管理写入和探测；现有连接摘要仍按原权限读取。关闭开关保留配置、密钥版本和审计记录。
