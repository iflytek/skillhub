# Add skill presentation fields

## Why
Skill packages currently expose only one description and cannot provide a concise card summary plus a richer detail overview without modifying package files.

## Scope
Add optional short description and Markdown overview to web and CLI-compatible publish metadata. Values are version snapshots, preserve package files, and use package metadata/default documentation when omitted. Public content changes only when the version publishes.

## Non-goals
No upload-free editing, database migration, i18n variants, or dedicated presentation file.
