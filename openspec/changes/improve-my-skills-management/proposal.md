# 统一控制台布局并优化“我的技能”管理页面

## Why

现有列表将更新、可见范围和治理动作平铺在卡片中，长名称、状态及元数据容易争抢空间。用户已确认独立卡片、统一筛选面板、权限感知的更多菜单，以及跳转详情、弹窗比较版本的交互方向。

单页原型落地后，用户进一步确认本轮统一控制台与设置页的共享外壳。控制台首页自行组织侧栏、子页使用不同宽度框架，造成跨页标题和侧栏位置不一致；列表还需覆盖长说明、状态补充提示及稳定多色的默认头像。

## What Changes

- 统一搜索、命名空间、胶囊状态筛选与结果总数，保留 URL 筛选和分页。
- 使用独立卡片组织标题、单一主状态、简介和元数据，保留待审目标及推广关联信息。
- 保留“更新”主要操作，将次要操作集中到更多菜单，遵守现有服务端权限和状态条件。
- 进入真实技能详情后支持返回列表上下文；版本比较采用居中弹窗。
- 补齐中英文本、键盘操作、窄屏及深色主题验证。
- 将共享外壳用于控制台首页、带侧栏的管理子页和设置页，统一侧栏、内容起点、中性背景及页头；表单保留阅读宽度、审核详情保留宽版。
- 说明与补充提示按实际内容展示：空简介不占位，有简介最多两行，不为其他卡片的提示预留空区；统一内边距而非强制等高，保留完整权限与审核信息。
- 默认技能头像按稳定标识选取柔和明暗配色，真实上传图片优先；以独立真实技能样例验证长短说明的显示。

## Impact

调整 Web 控制台与设置页的共享布局、技能卡片及其复用组件、测试和文档。沿用现有接口，不修改数据库、发布审核流程、权限判定和部署配置。市场、搜索、登录和公共技能详情不在本轮重设计范围；发布页保留无侧栏专用流程。PR #1043 的介绍字段缺陷单独处理；本变更不宣称解决该 PR 的业务问题。
