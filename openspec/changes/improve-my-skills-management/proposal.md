# 优化“我的技能”管理页面

## Why

现有列表将更新、可见范围和治理动作平铺在卡片中，长名称、状态及元数据容易争抢空间。用户已确认独立卡片、统一筛选面板、权限感知的更多菜单，以及跳转详情、弹窗比较版本的交互方向。

## What Changes

- 统一搜索、命名空间、胶囊状态筛选与结果总数，保留 URL 筛选和分页。
- 使用独立卡片组织标题、单一主状态、简介和元数据，保留待审目标及推广关联信息。
- 保留“更新”主要操作，将次要操作集中到更多菜单，遵守现有服务端权限和状态条件。
- 进入真实技能详情后支持返回列表上下文；版本比较采用居中弹窗。
- 补齐中英文本、键盘操作、窄屏及深色主题验证。

## Impact

仅调整 Web 管理页面及其复用组件、测试和文档。沿用现有接口，不修改数据库、发布审核流程、权限判定和部署配置。PR #1043 的介绍字段缺陷单独处理；本变更不宣称解决该 PR 的业务问题。
