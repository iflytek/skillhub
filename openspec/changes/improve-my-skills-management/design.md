# 技术与交互设计

## 范围与复用

以现有 `web/src/pages/dashboard/my-skills.tsx` 为入口，复用 TanStack Router、Query、现有 shadcn/Radix 组件、Lucide 图标和国际化资源。保留当前列表请求与分页，不增加逐卡片详情查询，不引入 UI 依赖。

筛选仍以 URL 的 `q`、`namespace`、`filter`、`page` 为事实源。结果数量仅取服务端 `total`；接口未提供完整状态统计，因此不显示各状态的伪数量。清除筛选统一清除四项条件并归零页码。

## 卡片与操作

卡片采用主题颜色、细边框、明确间距和可收缩的文本容器；标题与一个主状态分区，简介和元数据单独换行。保留当前可见范围、待审范围、只读原因和推广来源/目标，不用同名推断关联。

“更新”保留图标与文字，继续进入现有更新表单。“更多”采用具备可访问名称、键盘操作和焦点恢复的现有菜单组件。将当前操作条件从平铺按钮迁入菜单，不扩大权限、不增加删除能力。治理隐藏视图继续仅允许现有角色恢复。

现有操作契约以列表实现、`managementState` 及后端授权为准。操作矩阵如下；“普通视图”指非隐藏筛选且所有者非只读。

| 操作 | 可见条件 | 说明 |
| --- | --- | --- |
| 更新 | 普通视图、容器非 ARCHIVED | 进入原更新表单 |
| 可见范围 | 普通视图、ACTIVE、有发布版 | 存在待审版本时保留禁用反馈 |
| 撤回审核 | 普通视图、ownerPreview 为 PENDING_REVIEW | 次要动作互斥链的第一分支 |
| 推广或更新全局版 | 未命中撤审，服务端 canSubmitPromotion 且有发布版 | 使用真实推广关系和发布版 ID |
| 取消归档 | 未命中撤审及推广，容器为 ARCHIVED | 保留原确认步骤 |
| 归档 | 未命中以上分支，有发布版 | 保留原确认步骤 |
| 恢复隐藏 | HIDDEN 视图且 SUPER_ADMIN | 不展示所有者更新等操作 |

头像候选继续使用原 `previewOnly` 展示；不增加独立头像管理按钮。版本比较沿用现页规则，仅选择可访问的 PUBLISHED 版本且至少两个，不允许同一版本互比。

技能标题进入实际详情路由。返回上下文包含已有 `returnTo` 和列表滚动位置；导航状态不得跨技能、跨筛选错误复用。比较版本使用现有版本查询及差异组件，在用户打开居中 Dialog 时加载，保留加载、错误、空数据和重试状态。不得以抽屉替代。

## 兼容与风险

生命周期、当前范围与待审目标、推广关系沿用 `change-published-skill-visibility` 中的 REQ-VIS-05/06。退出命名空间后的所有者保持只读；前端菜单不是权限边界，服务端继续执行授权。重点回归菜单操作条件、点击冒泡、返回 URL/滚动、比较数据访问及移动端溢出。

## 验证方式

先完成一个可执行筛选切片并创建 Draft PR，再完成卡片和操作。实现收敛后执行一次集中独立 Review，随后冻结代码，形成需求追踪矩阵并运行源检查、精确提交镜像及浏览器关键业务路径。截图只证明视觉结果，不替代接口与最终状态断言。
