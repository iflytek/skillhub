# 技术与交互设计

## 范围与复用

以现有 `web/src/pages/dashboard/my-skills.tsx` 和 `web/src/app/layout.tsx` 为入口，复用 TanStack Router、Query、现有 shadcn/Radix 组件、Lucide 图标和国际化资源。保留当前列表请求与分页，不增加逐卡片详情查询，不引入 UI 依赖。

筛选仍以 URL 的 `q`、`namespace`、`filter`、`page` 为事实源。结果数量仅取服务端 `total`；接口未提供完整状态统计，因此不显示各状态的伪数量。清除筛选统一清除四项条件并归零页码。

## 卡片与操作

卡片采用主题颜色、细边框、明确间距和可收缩的文本容器；标题与一个主状态分区，简介和元数据单独换行。保留当前可见范围、待审范围、只读原因和推广来源/目标，不用同名推断关联。

“更新”保留图标与文字，继续进入现有更新表单。“更多”采用具备可访问名称、键盘操作和焦点恢复的现有菜单组件。将当前操作条件从平铺按钮迁入菜单，不扩大权限、不增加删除能力。治理隐藏视图继续仅允许现有角色恢复。

现有操作契约以列表实现、`managementState` 及后端授权为准。操作矩阵如下；“普通视图”指非隐藏筛选且所有者非只读。

| 操作 | 可见条件 | 说明 |
| --- | --- | --- |
| 更新 | 普通视图、容器非 ARCHIVED | 进入原更新表单 |
| 可见范围 | 普通视图、ACTIVE、有发布版 | 存在待审版本时保留禁用反馈 |
| 撤回审核 | 普通视图、ownerPreview 为 PENDING_REVIEW | 次要动作互斥链的第一分支 |
| 推广或更新全局版 | 未命中撤审，服务端 canSubmitPromotion 且有发布版 | 使用真实推广关系和发布版 ID |
| 取消归档 | 未命中撤审及推广，容器为 ARCHIVED | 保留原确认步骤 |
| 归档 | 未命中以上分支，有发布版 | 保留原确认步骤 |
| 恢复隐藏 | HIDDEN 视图且 SUPER_ADMIN | 不展示所有者更新等操作 |

头像候选继续使用原 `previewOnly` 展示；不增加独立头像管理按钮。版本比较沿用现页规则，仅选择可访问的 PUBLISHED 版本且至少两个，不允许同一版本互比。

技能标题进入实际详情路由。返回上下文包含已有 `returnTo` 和列表滚动位置；导航状态不得跨技能、跨筛选错误复用。比较版本使用现有版本查询及差异组件，在用户打开居中 Dialog 时加载，保留加载、错误、空数据和重试状态。不得以抽屉替代。

确认框关闭后恢复原操作入口；查询结果异步移除原行且焦点落回页面主体时回退到列表搜索控件，用户已聚焦其他控件时不抢夺焦点。

## 兼容与风险

生命周期、当前范围与待审目标、推广关系沿用 `change-published-skill-visibility` 中的 REQ-VIS-05/06。退出命名空间后的所有者保持只读；前端菜单不是权限边界，服务端继续执行授权。重点回归菜单操作条件、点击冒泡、返回 URL/滚动、比较数据访问及移动端溢出。

## 验证方式

先完成一个可执行筛选切片并创建 Draft PR，再完成卡片和操作。实现收敛后执行一次集中独立 Review，随后冻结代码，形成需求追踪矩阵并运行源检查、精确提交镜像及浏览器关键业务路径。截图只证明视觉结果，不替代接口与最终状态断言。


## 原型视觉基线与管理页面范围

以已确认原生 Figma 稿及最终执行生成脚本为视觉来源，原生 Medium 字重采用500；本地 HTML 仅作辅助对照；旧覆盖前的30px操作高度不作为基线。用户追加确认将外壳和页头推广至控制台与设置页，卡片紧凑字号仅作用于技能列表，不将11px元数据字号套用到表单正文。

| 区域 | 本页基线 | 生产适配 |
| --- | --- | --- |
| 标题／简介／元数据／状态 | 15px/24px、12px/20px、11px/18px、10px/20px | 桌面标题列390px、可收缩，后接状态；窄屏不固定列宽且最多两行，完整名称保留于title及详情 |
| 状态与图标 | 状态圆角5px、内边距0/7px、低饱和底色；元数据图标13px | 小字前景色加深到4.5:1对比；真实头像或首字回退32px，不推断技能类别 |
| 卡片与操作 | 圆角12px、卡片间距12px、桌面内边距18px/20px、移动14px | 更新72×32px、更多32×32px；768px以下更新进入菜单，保留相同权限及预填参数 |
| 页面框架 | 控制台及设置页共享1440px外壳、224px侧栏，桌面右栏左右40px、顶部36px | 手机左右16px、顶部18px；侧栏桌面20px水平／32px顶部及移动16px内边距，设置表单限制阅读宽度，审核详情可使用1500px宽版 |
| 筛选与菜单 | 筛选控件40px、胶囊32px；菜单宽208px、圆角10px、条目36px、图标16px；发布按钮36px | 不伪造状态计数；浅色与深色分别适配 |

原型中的彩色类别头像与固定技能数据是演示样例，不能据此生成生产语义；真实技能图片、生命周期、只读状态与审核目标仍来自现有接口。短可见性标签和图标旁保留完整范围说明，长坐标可截断但保留完整悬停文本及复制操作；768px以下隐藏下载统计，桌面仍展示。公共导航高度及内容继续遵循应用外壳，不宣称整个应用逐像素复刻原型。

## 统一外壳、说明高度与默认头像

- 控制台首页删除页内重复侧栏，由公共 Layout 与其他管理页统一组织。导航过滤仅保留现有角色与能力规则；外壳和侧栏的路径判断使用同一个已解析路由，防止加载期间组合新外壳与旧内容。
- 发布页继续使用无侧栏流程，市场、搜索、登录及公共技能详情不进入本轮管理外壳。设置表单在右栏内左对齐并限制阅读宽度；较宽审核内容以明确模式保留，不为每个页面另写位置特例。
- 常规管理与设置页面复用统一页头。命名空间和审核资源详情本轮继承共享外壳，保留资源型标题和专用内容结构，后续随详情页风格改造处理；不得通过管理外壳下的通用 `h1` 选择器污染 Markdown 正文或公共资源组件。
- 技能列表常规说明位预留两行；当前页任一卡片有推广关系、申请范围或只读提示时，各卡片统一预留一行补充区。没有提示的整页不保留该空行；提示可换行，手机或风险说明、头像预览允许自然增高，不使用固定高度裁切内容。完整说明保留文本提示及真实详情入口。
- 头像组件提供可选稳定种子，以命名空间与技能标识散列映射有限柔和配色，包含明暗主题；不调用渲染期随机数，不按展示名猜测行业或类别。列表显式传入种子，既有未选用此能力的调用保持原样。真实图片优先，失败时使用相同种子的首字回退。
- 长短说明样例使用独立命名前缀，通过真实上传和现有审核流程建立；不得修改已有版本差异、状态和分页回归所依赖的数据。验收比较元数据对齐、提示集中、截断后的完整内容可达性，以及刷新或改名后的默认头像一致性。
