# 首页精选与专题策划

## Why

Issue #1035 的展示字段已由独立工作交付，首页仍缺少管理员策划的新人入口。复用 #1074 的数据库配置基础，按已确认的 V12 页面与交互实现推荐内容，避免仅有浏览器内存原型或将普通 RECOMMENDED 标签误作平台授权。

## Scope

- REQ-01：复用 system_setting，独立保存推荐草稿与发布快照；版本检查、权限和审计沿用现有配置模式。原站点信息仍保存即生效。
- REQ-02：SUPER_ADMIN 可策划首页精选、专题名称/简介/封面及关联技能；数组顺序即展示顺序。专题不是套件或普通技能标签。
- REQ-03：管理员页面默认展示草稿效果；配置在事务弹窗完成。取消不写父草稿，应用后可保存、预览、确认发布。拖拽只从手柄启动，支持鼠标、触屏、键盘和 Esc 恢复。
- REQ-04：真正首页展示已发布的专题轮播与精选技能；专题及全部精选可通过真实只读路由浏览，沿用技能详情链接。
- REQ-05：公开读与候选选择强制采用匿名公开资格，按当前可见性、容器/空间状态、治理与已发布生命周期过滤；不可用技能不得泄露 ID、名称、简介或计数。
- REQ-06：初始推荐仅解析当前实际安装、builtin publisher 所有且公开可用的预设技能；不可假定 manifest 已全部安装。明确发布空配置后保持空配置。预设标签补齐须幂等且不覆盖人工维护。
- REQ-07：复用已有限制 PNG/JPEG 资产上传；限制配置体积，处理冲突、权限拒绝、保存失败和过期/不可用引用。
- REQ-08：系统配置采用统一分区导航并复用现有站点、账号审核、通知维护表单，不改变其保存或安全语义。按仓库设计系统采用真实 React 组件，不全局引入原型 CSS/JS。
- REQ-09：补充中英文操作文档、四语言 UI、OpenAPI 与有意义的后端/前端/浏览器验收。
- REQ-10：按确认的 V17 统一站点配置布局、胶囊导航、图片上传和组件状态；取消编辑页常驻预览，通过宽版只读弹窗预览未保存配置，关闭后保留编辑内容。
- REQ-11：站点首页模块支持平台精选显隐，沿用站点配置保存及公开读取。旧配置缺少该键时继续显示；关闭不删除推荐草稿、发布快照或专题内容。
- REQ-12：登录与审核采用独立保存面板及首次授权规则列表/编辑弹窗；通知与维护采用邮件配置、投递记录、索引维护胶囊分区，保留真实权限、接口、冲突和危险操作确认。
- REQ-13：分区切换检查未保存编辑，忙碌操作防止重复提交/中途退出；四语言、明暗、键盘、焦点与窄屏均使用项目现有组件契约，避免将离线原型模拟行为当作后台能力。

- REQ-14：按已确认 V21 将公共推荐入口的专题卡在原专题推荐区域内展开为技能集合；B 方案仅用于精选/专题卡，保留独立专题链接与后台事务编辑语义。
- REQ-15：自定义封面完整保持比例、小图不放大、标题独立、失败可回退；外壳展开与实际内容分离，覆盖焦点、关闭、中断、减少动态和移动布局。

- REQ-16：按 V22 修正，展开替换原专题轮播，不创建弹窗或详情阅读区；移除每项技能的使用说明，查看技能后返回恢复该历史条目的专题、筛选、轮播与滚动状态。

## Not in scope

不引入推荐算法、租户、额外审核流程、技能自动发布、任意 HTML/脚本、外链封面抓取、新配置数据库或对站点其他页面的无关重设计。原型数据不能成为真实接口数据。
