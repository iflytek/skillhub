# 产品采用

主题源是 colors_and_type.css，完整亮暗投影为 tokens.full.json；44份组件契约位于 components/index.json 的 contractData。
读取顺序与真实命令见 ../README.md；先确认当前版本和内容，再按任务读取主题、组件及规范正文。

产品使用现有 React 组件、业务接口与权限契约。设计示例描述视觉目标，不保证相同 props 已实现；不把原型演示数据当作后端能力。
静态 HTML 示例允许使用 components.runtime.css；preview CSS 和示例脚本仅服务演示。
Agent 读取与验收按仓库前端规范；不依赖未提供的编辑器插件、画板桥接或私人路径。
