# 图形规范

以中性黑白体系和文字标识为基础；品牌更换需单独审阅，不从示例推断全站重设计授权。

### 字标规格

| 项 | 规格 | 来源 |
|---|---|---|
| 文字 | `SkillHub`（大小写固定，不写 SKILLHUB / Skill Hub） | 品牌名 |
| 字体 | `--sh-font-sans` 600（PingFang SC 起始的中英同源栈，与 `body` 实际解析一致） | 0.5.9 |
| 字距 | `-0.02em` | 现有（标题风格） |
| 颜色 | 浅色 `--sh-text-primary`；深色 `--sh-text-primary` | 现有 |
| 最小尺寸 | 数字界面 96 × 24 px；印刷/导出 ≥ 160 × 40 px | 扩增，需评审 |
| 留白 | 四周 ≥ 12px 或 0.5 倍字高（取较大值） | 扩增 |
| 位置 | 全站左上角页头；详情页可缩小但不得低于最小尺寸 | 现有布局 |

**可用**：纯文字、单色、水平排列；与 `@namespace` 徽标分开摆放。
**不可用**：旋转、拉伸、描边、投影、渐变填充；把字标与命名空间徽标拼成一体锁合；在图片/截图上不加遮罩直接压字；用字标当按钮。

## 6. 图标系统

产品复用已安装的 lucide-react；静态资源见 assets/icons 与 assets/icons.css。尺寸、光学边界和可访问名称按[图标规范](./icons.md)。

## 7. 空态与状态视觉

**现状确认：`web/src/shared/components/empty-state.tsx` 是「图标 + 标题 + 说明 + 可选操作」，没有插画资产。**

**决定：不引入插画。** 理由：
1. 仓库无插画资产与插画规范，临时引入会与黑白极简体系冲突；
2. 空态出现频率高，插画会拖慢首屏并增加多语言维护成本；
3. 图标 + 一句可执行文案已经足够表达“为什么空 + 下一步”。

边界：
- 图标固定 24px，`--sh-text-tertiary`；不允许彩色大图。
- 允许状态色只用于「错误/警告」空态的一个图标，面积不超过 24 × 24。
- 宁可用文字不用图标：破坏性确认、密集表格内状态、终端/日志输出、需要精确语义的合规提示。
- loading 骨架不得用插画替代；空态与错误态的真实渲染见 `preview/stress-states.html`。

## 8. 数据可视化

**现状：`web/package.json` 无图表库（recharts / echarts / chart.js / d3 均未安装），页面没有图表。**
**决定：当前不定义业务图表色，只在 token 中预留 `--sh-chart-1…4`、`--sh-viz-accent`、`--sh-viz-grid`、`--sh-viz-axis`，标注“扩增项，需评审”。**

若未来引入图表，按以下顺序使用（中性优先、单色强调）：
1. 灰阶承担分类：`#212121 → #737373 → #a3a3a3 → #d4d4d4`（暗色反向）；
2. 只允许一个强调色 `--sh-viz-accent`，用于“当前选中/主指标”，面积占比 ≤ 20%；
3. 网格线 `--sh-viz-grid`，坐标文字 `--sh-viz-axis`；
4. 相邻灰阶对比 ≥ 1.5:1，强调色与背景 ≥ 3:1；文字与背景 ≥ 4.5:1。

不做：多色霓虹系、渐变面积图、3D、饼图超过 4 类。

## 9. 数据展示

数字、单位、表格与空值是“看着乱”的高发区，逐条约束如下。字符规则见 [`content-i18n.md`](./content-i18n.md) §3。

### 9.1 数字

| 项 | 规则 | 实现 | 示例 |
|---|---|---|---|
| 数字字体 | 统一 `--sh-font-sans` + `font-variant-numeric: tabular-nums`；**不用等宽字体**（等宽只给 ID / 端口 / 坐标） | `font-variant-numeric:tabular-nums` | `1,284`、`4.6` |
| 千分位 | 半角逗号，从右每 3 位 | `Intl.NumberFormat` | `12,480` |
| 小数位 | 同一列固定位数；评分 1 位，百分比 0 或 1 位，不在同列混用 | `toFixed` 或 `Intl` | `96%`、`4.6` |
| 大数缩写 | ≥ 100,000 才缩写为 `128.4k` / `1.2M`；缩写列必须给完整值 tooltip | — | `128.4k` |
| 百分比 | 数字与 `%` 无空格；涨跌用 `+3.2%` / `-1.8%`，不用箭头代替符号 | — | `+3.2%` |
| 负数 | 半角减号 `-`，不用 `–` / `−`；与数字不空格 | — | `-12` |
| 计数单位 | 数字 + 空格 + 量词 | — | `128 次安装`、`6 个版本` |
| 评分 | `4.6 / 5`，斜杠两侧空格；不写 `4.6分` | — | `4.6 / 5` |

### 9.2 单位与文件大小

- 文件大小：十进制、两位有效数字以内、数字与单位一个空格：`10 MB`、`1.2 GB`、`860 KB`；不使用 `MiB`。
- 时间：≤ 7 天相对（`3 天前`），更久用绝对日期 `2026-11-05`；同列不混用相对与绝对。
- 时长：`150ms`、`1.6s`、`2 分钟`；毫秒不带空格。
- 版本号：`v1.4.0`，`v` 小写且与数字不空格；列表中版本号用 `--sh-font-mono`。

### 9.3 表格对齐

| 列类型 | 对齐 | 说明 |
|---|---|---|
| 文本（技能名、命名空间、描述） | 左对齐，单元格 `min-width:0` + 单行省略 | 名称不得居中 |
| 数值（安装量、下载量、评分数） | 右对齐 + `tabular-nums` | 与表头同对齐 |
| 日期 | 左对齐或右对齐**全表统一**，同表不混用 | 推荐右对齐 |
| 状态 / 徽标 | 左对齐；列宽固定为最宽徽标 + `--sh-space-2` | 徽标不换行、不拉伸 |
| 操作 | 右对齐 | 主操作在最右 |
| 空值 | 见 9.4 | — |

规则：表头与单元格同对齐；列宽由最宽内容决定，不按百分比均分；数值列不与文本列共用同一 `text-align`。

### 9.4 空值与零

| 情况 | 写法 | 反例 |
|---|---|---|
| 字段无值 / 未提供 | `—`（em dash, U+2014），`--sh-text-tertiary` | `-`、`N/A`、`null`、空白 |
| 数值确实为 0 | `0`，正常前景色 | `—`（零不是空） |
| 列表整体为空 | 空态块（图标 + 一句可执行文案），不是一行 `—` | `暂无数据` |
| 加载中 | 骨架行，不是 `—` | `加载中…` 占位文本 |
| 错误导致无值 | `—` + 行内错误 tooltip | `0`（避免误读为真实零值） |

- 同一列空值符号必须一致；不得一处 `—` 一处 `N/A`。
- 空值不参与排序权重计算（置底），不显示为 `0`。

## 10. 禁用做法（汇总）

1. 新增第二套图标库，或手写 SVG 替代 lucide 已有图标。
2. 用 emoji 当功能图标；给图标叠加第二种强调色（状态色除外，一屏最多一处）。
3. 新增未登记的资产文件；文件名带 `final` / `v2` / `new`。
4. 在资产里使用库外颜色（含产品 favicon 的蓝色系）。
5. 把品牌字标与命名空间徽标拼成锁合图形。
6. 用整页截图或 README 全文做封面/OG。
7. 用位图承载可缩放的字标与图标；图标一律 SVG。
