# 文案与 i18n 规范

> 本规范的目标是「能查表用」：术语统一、长度有上限、截断有规则。所有上限按**字符数**给出，像素只作参考；中文单字宽度约为拉丁字母的 2 倍，**不能按“中文比英文短”估宽**。实测方法见第 6 节与 `preview/stress-*.html`。

## 1. 术语表（中文 / English / Русский）

统一用词，禁止同义替换。俄文给主格单数；进入句子时按语法变格，但词干不得改变。

| # | 中文 | English | Русский | 备注 |
|---|---|---|---|---|
| 1 | 技能 | skill | навык | 产品核心对象，不译作“插件” |
| 2 | 技能包 | skill package | пакет навыка | 指 zip 包本体 |
| 3 | 命名空间 | namespace | пространство имён | 坐标为 `@namespace/skill` |
| 4 | 版本 | version | версия | 与语义化版本号配合 |
| 5 | 发布 | publish | опубликовать | 动作结果：已发布 |
| 6 | 撤回 | withdraw | отозвать | 审核中撤回，不离开版本列表 |
| 7 | 下架 | yank | снять с публикации | 已发布版本撤下 |
| 8 | 审核 | review | проверка | 含“待审核 / 审核中” |
| 9 | 安装 | install | установить | 安装次数 = installs / установки |
| 10 | 下载 | download | скачать | 与“安装”区分：下载包文件 |
| 11 | 上传 | upload | загрузить | 上传新版本 |
| 12 | 成员 | member | участник | 命名空间成员 |
| 13 | 权限 | permission | разрешение | 第 4 个 Tab 的名称 |
| 14 | 维护者 | maintainer | сопровождающий | 技能负责人 |
| 15 | 标签 | label | метка | 分类/筛选标签 |
| 16 | 评分 | rating | оценка | 5 分制 |
| 17 | 星标 | star | звезда | 收藏动作 |
| 18 | 订阅 | subscription | подписка | 更新通知 |
| 19 | 组织 | organization | организация | 企业/团队上级单位 |
| 20 | 校验 | checksum / validation | проверка целостности | 包完整性校验，勿与“审核”混用 |
| 21 | 错误提示 | error message | сообщение об ошибке | 字段级或页面级 |
| 22 | 空态 | empty state | пустое состояние | 无数据时的呈现 |

规则：
- 同一动作全站只用一个词：安装（install / установить）、发布（publish / опубликовать）、撤回（withdraw / отозвать）、下架（yank / снять с публикации）。
- 破坏性操作用“删除 / 移除 / 撤回”，不用“清理”。
- 技术名词保留原文：`SKILL.md`、`namespace`、`ClawHub CLI`、`Token`；不硬译成“技能描述文件”。

## 2. 中英混排

- 中文与拉丁字母/数字之间加一个半角空格：`使用 SKILL.md 文件`、`支持 3 种模式`。
- 中文与中文标点之间不留空格；英文句子内使用英文标点。
- 全角标点只用于中文正文；代码、命令、URL、路径一律半角。
- 禁止中英混写同一短语（如“安装 install 命令”），要么全中文，要么保留英文术语。
- 俄文正文中的拉丁技术词同样前后留空格；不要用中文标点。

## 3. 数字与单位

| 类型 | 规则 | 示例 |
|---|---|---|
| 千分位 | 半角逗号 | `1,284` |
| 百分比 | 数字与 `%` 不留空格 | `96%` |
| 文件大小 | 数字 + 空格 + 单位，十进制 | `10 MB`、`1.2 GB` |
| 次数/数量 | 数字 + 空格 + 中文量词 | `128 次安装`、`6 个版本` |
| 版本号 | `v` + 语义化版本 | `v1.4.0` |
| 评分 | 一位小数 + `/ 5` | `4.6 / 5` |
| 代码/端口/ID | 等宽字体，不换行 | `8080`、`local-user` |
| 英文数量 | 复数按 i18next `_one/_other` | `1 install` / `12 installs` |
| 俄文数量 | 按 `_one/_few/_many` 三套复数 | `1 установка` / `3 установки` / `12 установок` |

## 4. 日期与时间

- 机器可读 / 表格：`2026-11-05`（ISO，本地时区 `Asia/Shanghai`）。
- 中文展示：`2026 年 11 月 5 日`；英文：`Nov 5, 2026`；俄文：`5 ноября 2026 г.`（由 i18next 本地化，不手拼）。
- 相对时间：≤ 7 天用「3 天前 / 2 小时前」；超过 7 天用绝对日期。
- 时间戳必须带时区语义；前端展示用 `Intl.DateTimeFormat`，不要手拼字符串。

## 5. 长度上限（按字符，不是字节）

字符上限是最长语言的**硬上限**，超过即视为文案不合格，需改写而不是继续压缩字号。像素列为 14px 正文下的参考宽度。

| 元素 | 中文 | English | Русский | 参考宽度 / 行数 | 溢出策略 |
|---|---|---|---|---|---|
| 主按钮 | 8 | 20 | 26 | 160px / 1 行 | 不换行；超出改写短文案 |
| 次按钮 | 10 | 24 | 30 | 140px / 1 行 | 不换行；超出改写 |
| 对话框按钮 | 12 | 28 | 34 | 200px / 最多 2 行 | 允许两行，行高 1.35 |
| Tab | 4 | 10 | 12 | 96px / 1 行 | 不换行；超出用图标 + tooltip |
| 徽标 / 状态 | 6 | 14 | 16 | 96px / 1 行 | 单行省略 |
| 输入框 label | 12 | 40 | 44 | 1 行，允许折 2 行 | 不省略；超出改写 |
| placeholder | 10 | 30 | 34 | 控件内 1 行 | 单行省略；不得承载关键信息 |
| 帮助文案 | 40 | 100 | 110 | 2 行 | 超出改写，不用滚动 |
| 字段错误 | 40 | 90 | 100 | 2 行，紧贴控件 | 必须完整显示，允许 3 行 |
| 页面错误 | 60 | 140 | 160 | 3 行 + 重试 | 必须完整显示 |
| 卡片标题 | 24 | 56 | 60 | 2 行 | 第二行省略，完整名在详情页 |
| 卡片描述 | 80 | 160 | 180 | 2 行 | 两行截断 |
| 列表项标题 | 16 | 40 | 44 | 1 行 | 单行省略 |
| 列表项描述 | 60 | 120 | 130 | 2 行 | 两行截断 |
| 表格单元格 | 12 | 32 | 36 | 1 行 | 单行省略，完整值进 tooltip |
| 表格技能名 | 24 | 56 | 60 | 2 行 | 两行截断，命名空间单独一行 |
| Toast | 30 | 60 | 70 | 2 行，360px | 超出改写 |

- 俄文通常比英文长 30–40%，**所有按钮/标签布局必须容忍 1.4 倍英文长度**。
- 160 字符的英文描述 ≈ 80 个汉字 ≈ 180 个俄文字符；三者共用同一字符上限表，不做“按语言切换字号”。
- 任何新增文案必须在 `preview/stress-form.html` / `stress-list.html` / `stress-table.html` 里替换占位文案实测一次，再回填到产品。

## 6. 截断与混排实现规则

| 场景 | 规则 | 最小实现 |
|---|---|---|
| 表格技能名 / 命名空间 | 单行省略；命名空间独立一行、等宽字体 | `overflow:hidden;text-overflow:ellipsis;white-space:nowrap` |
| 列表项标题 | 单行省略；不在标题里拼命名空间 | 同上，父级需 `min-width:0` |
| 卡片标题 | 两行后省略；完整名在详情页可读 | `display:-webkit-box;-webkit-line-clamp:2;-webkit-box-orient:vertical` |
| 描述 / 帮助文案 | 两行截断；不使用滚动 | 同上，`line-height` 固定 |
| 俄语长复合词 | 允许在任意位置断行，不断字 | `overflow-wrap:anywhere`；容器加 `lang="ru"` 以启用 `hyphens:auto` |
| 数字列 | 等宽数字、右对齐 | `font-variant-numeric:tabular-nums;text-align:right` |
| 按钮文案 | 工具栏内不换行；对话框允许两行 | `white-space:nowrap` 或 `white-space:normal;line-height:1.35` |
| 完整技能名 / 安装命令 / 错误信息 | **禁止截断** | 允许换行，容器 `overflow-wrap:anywhere` |

- 禁止用 `white-space: nowrap` 覆盖所有文本；只对按钮、Tab、徽标、表格单元格使用。
- 任何 `flex` / `grid` 里的可截断文本，父级必须显式 `min-width: 0`，否则省略号不生效。
- 语言属性必须写在语言块上（`<section lang="en">` / `<section lang="ru">`），不要只在根节点写 `lang="zh-CN"`。

## 7. i18n 实现约束

- 文案 key 按 `domain.component.action` 命名（如 `skill.detail.install`），不拼句子片段。
- 禁止字符串拼接生成语序；用 i18next 插值 `{{count}}` 与复数规则（俄文必须配置 `_one/_few/_many`）。
- 中文文案直给：动词开头、说清结果；禁用“赋能/一键智达/全新升级”等营销词。
- 英文：句首大写、按钮用动词原形（Install / Publish / Withdraw），不使用 Title Case 长句。
- 俄文：按钮用完成体动词（Опубликовать / Отозвать），错误句用「Что произошло + 下一步」两段式。
- 所有文案进入产品前，先在本库压力预览页验证长度；不允许只在中文字符数下验收。

## 8. 字体栈（0.5.9 起）

`--sh-font-sans` 与 `--sh-font-heading` 使用同一套**系统字体栈**，按平台可用性排序，不依赖未打包的 Web 字体：

```css
--sh-font-sans: 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

| 优先级 | 字体 | 覆盖平台 | 作用 |
|---|---|---|---|
| 1 | PingFang SC | macOS / iOS | 中文 + 拉丁同源，字重与基线一致 |
| 2 | Hiragino Sans GB | macOS（旧版） | 中文回退 |
| 3 | Microsoft YaHei | Windows | 中文回退 |
| 4 | Noto Sans SC | Linux / Android | 中文回退 |
| 5 | -apple-system / BlinkMacSystemFont / Segoe UI | 各平台 | 纯拉丁兜底，保证数字与控制字符不缺失 |

规则：

- **不引入未打包的 Web 字体**：`Plus Jakarta Sans` 未随库分发，首位声明会让拉丁字符回落到 `.SF NS`、中文用 PingFang SC，出现粗细与基线不一致；已移除。需要品牌字体时，必须同时提供 `@font-face` 与字体文件，再升 MINOR。
- **中文标题不改字族**：层级只用 400 / 500 / 600 字重与字距表达，`--sh-font-heading` 与 `--sh-font-sans` 同值。
- **代码与坐标仍走** `--sh-font-mono`，不得用 sans 栈模拟等宽。
- 换栈会让拉丁字宽轻微变化（实测详情页导语首行 742 → 749 px，行数不变）；新增固定宽度容器时按最长文案实测，不要按旧栈宽度写死。
- 产品侧 `web/src/index.css`（Plus Jakarta Sans）与 `tailwind.config.ts`（Inter）尚未同步，登记为 G-006，等前端负责人排期。

## 9. 文案语气与按钮动词

### 9.1 语气

| 场景 | 写法 | 正例 | 反例 |
|---|---|---|---|
| 按钮 / 菜单 | 动词开头，2–4 字，说清结果 | `安装`、`提交审核`、`删除版本` | `确定`、`好的`、`一键安装` |
| 字段帮助 | 陈述能做到什么，不写“请注意” | `最多 10 MB，支持 zip` | `请注意文件大小不要太大` |
| 字段错误 | 发生了什么 + 怎么改，两段一句话 | `文件名重复，请换一个名称` | `出错了`、`格式不正确` |
| 空态 | 为什么空 + 下一步动作 | `还没有技能，先上传一个` | `暂无数据` |
| 危险确认 | 后果 + 影响范围 + 是否可逆 | `删除后 6 个版本不可恢复` | `此操作不可撤销`（不说范围） |
| 成功反馈 | 结果，不加感叹 | `已发布 v1.2.0` | `太棒了！发布成功！` |

规则：
- 不用营销词：`赋能`、`一键智达`、`全新升级`、`极致体验`。
- 不用拟人化自称：不写“我们觉得”，写“系统会”。
- 不用双重否定与反问；不使用感叹号堆叠，一屏最多 1 个 `!`。
- 中文句长 ≤ 30 字/句；超过即拆成两句，不用逗号硬连四个分句。
- 标点：中文正文全角，代码/命令/路径半角；句末不加句号（按钮、徽标、Toast、字段错误一律无句号）。

### 9.2 按钮动词（全库唯一写法）

| 动作 | 中文 | English | Русский | 用于 |
|---|---|---|---|---|
| 安装到 Agent | `安装到 Agent` | `Install to Agent` | `Установить в Agent` | 详情页主操作 |
| 安装（计数语境） | `安装` | `Install` | `Установить` | 列表卡、统计 |
| 提交审核 | `提交审核` | `Submit for review` | `Отправить на проверку` | 草稿 → 待审 |
| 撤回 | `撤回审核` | `Withdraw` | `Отозвать` | 待审 → 已上传，**不写“撤销”** |
| 删除版本 | `删除版本` | `Delete version` | `Удалить версию` | 破坏性，红色 |
| 下架 | `下架` | `Yank` | `Снять с публикации` | 已发布 → 已下架 |
| 复制命令 | `复制命令` | `Copy command` | `Скопировать команду` | 代码块 |
| 应用筛选 | `应用筛选` | `Apply filters` | `Применить фильтры` | 筛选面板 |
| 重置 | `重置` | `Reset` | `Сбросить` | 筛选/表单，不用“清空” |
| 新建技能 | `新建技能` | `New skill` | `Новый навык` | 列表页主操作 |
| 查看全部版本 | `查看全部版本` | `View all versions` | `Все версии` | 次级链接 |
| 取消 / 关闭 | `取消` / `关闭` | `Cancel` / `Close` | `Отмена` / `Закрыть` | 对话框；`取消` 不替代 `关闭` |

规则：
- 同一动作全站一个词，不得出现 `撤销` / `撤回` 混用；`清理` 只用于缓存/临时文件，不用于业务对象。
- 破坏性按钮必须写出对象（`删除版本` 而非 `删除`），且不得与主按钮同色。
- 对话框按钮 = 动作动词 + 取消；不使用 `确定 / OK`。
- 英文按钮动词原形、首字母大写、其余小写；俄文用完成体。
- 新增按钮文案先在 `preview/component-button.html` 的 sm/md/lg 三档实测 8 / 10 字符上限，再进产品。
