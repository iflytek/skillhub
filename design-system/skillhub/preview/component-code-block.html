CodeBlock 代码块

code-block

安装命令与 API 示例的统一呈现。命令完整展示、不省略、不截断，复制时不带 $ 提示符。

  • 等宽字体 13px
  • 复制按钮 28px
  • 两种安装方式分行展示
  • 深色底仅用于落地页

01浅色 · 单行安装命令

技能详情页首屏使用。浅灰底、1px 描边、圆角 8px、内边距 10px 12px；命令单行完整可读。

技能详情页 · 安装命令

clawhub install @global/chinese-office-assistant

命令前不加 $ 提示符，复制内容即为可执行命令。

02两种安装方式 · 分行展示

SkillHub CLI 与 ClawHub CLI 并列成行，明确标注来源；不使用 Tab 隐藏其中一种。

SkillHub CLI

企业内部注册表的默认方式，携带版本号。

npx @astron-team/skillhub@latest install @global/chinese-office-assistant --version 1.4.0

ClawHub CLI

保留既有 ClawHub 工作流的项目继续使用兼容 slug。

npx clawhub install chinese-office-assistant

03复制按钮 · idle / copied

复制图标位于代码块右上角；复制成功后切换为对勾，1.5s 后恢复，并弹出「已复制」提示。

clawhub install @global/chinese-office-assistant

idle · 复制

ghost 28px 图标按钮，悬停显示 --sh-accent-base 底色。

clawhub install @global/chinese-office-assistant
已复制

copied · 已复制

图标切换为对勾，1.5s 后恢复为复制图标。

04深色变体 · 落地页

落地页与营销区块使用 --sh-code-bg 深色底、--sh-code-fg 浅色文字；详情页仍使用浅色变体。

中文办公助手

深色代码块仅用于落地页，不用于技能详情页的安装命令区域。

05规格与书写规则

代码块服务于「可复制」这一目标：宁可换行，也不省略任何命令内容。

字体与字号

JetBrains Mono / 等宽栈，13px，行高 1.6

浅色容器

背景 --sh-bg-muted，1px --sh-border-default，圆角 8px

复制按钮

28 × 28px，绝对定位 right 8 top 8，悬停 --sh-accent-base

长命令

pre-wrap + break-all，整行完整可读，不使用省略号截断

提示符

命令前不加 $，避免复制时误带符号

复制反馈

图标切换为对勾，toast 文案「已复制」，1.5s 后恢复

不使用彩色语法主题，也不给大量代码加行号。本页为静态预览，复制按钮不执行实际复制。

所有颜色、间距、圆角与动效均来自 colors_and_type.css；本页为静态预览，不含脚本。
