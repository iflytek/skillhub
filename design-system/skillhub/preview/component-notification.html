Notification 通知浮层

右上 / 右下固定宿主上的轻量通知卡，360px 宽、12px 内边距、四边统一 1px 中性边框。四档 info / success / warning / error 只靠图标着色区分，卡片本体不染色、不画左侧色条；进场 200ms 上移淡入，退场 150ms 淡出。与行内 loading-chip 分工：浮层只用于「结果已发生」的异步反馈。

四档语义 info / success / warning / error

语义只落在 16px 图标上（tone-fg），卡片底色保持 raised，不整块染色，也不加左侧色条：亮色下 tone-fg 是 #8f1c12 这类深酒红，做 3px 实心竖条会显得过于「AI 感」。标题 13/500，说明 13 可换行。
