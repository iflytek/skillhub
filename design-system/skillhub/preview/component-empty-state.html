no-data / block · 高度 240px，单个 outline 操作

契约要点

  • 图标 32px，颜色 --sh-text-tertiary，只用线性图标。
  • 标题 14px / 500；说明 13px --sh-text-secondary，交代原因与下一步。
  • block 高度 240px，inline 高度 96px，compact 高度 64px；高度由容器 className 传入。
  • 最多一个操作按钮，使用 outline / sm（32px 高）样式。
  • 加载中不使用空态，改用 Skeleton 占位。

no-data / inline 与 no-search-result

inline 只保留一句 13px 说明，适合侧栏或分组内的小面积空态；搜索无结果不提供操作按钮。
