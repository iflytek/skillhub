TextLink 正文链接

段落与说明文字内的导航链接。按钮、行内操作、卡片操作必须使用 .btn / .btn-link / .action，不要用正文链接承担操作语义。

基本用法 段落内 / 说明内

发布前请先阅读 发布规范，版本撤回与下架流程见 治理说明。正文链接保留下划线，确保在中文长段落中仍可被识别。

与操作语义的分界 正文链接 ≠ 按钮

正文链接只做导航，不改变当前页面的业务状态；复制命令、安装、提交审核、撤回版本属于操作，应使用 .btn 或 .btn-link，并由 .btn 统一复位下划线。

卡片内的说明文字可以带正文链接，例如 查看安全扫描报告。

卡片内的操作入口不用下划线链接，请使用按钮或 .btn-link，见 component-button.html。

禁忌 三条红线

  • 01不要用全局 a { text-decoration: none } 复位正文链接；只对 .btn / .action 定向复位。
  • 02正文链接不要改成实心按钮或胶囊按钮，避免与主操作争夺视觉层级。
  • 03正文链接不要依赖颜色单独传达可点击性，下划线必须保留。
