结构 Overlay / Content / Header / Body / Footer

宽度档位

--sm 360 / --md 480 / --lg 640；窄屏统一收到 100vw − 32px，不横向溢出。宽度由内容决定档位，不随手写死。

遮罩与定位

遮罩与面板都挂在 .sheet-layer（fixed inset:0，z-overlay）里；点击遮罩关闭、Esc 关闭、打开时焦点进入面板。

Radix Dialog

根节点复用 Dialog + Overlay 组合，不引入新依赖，不新增 Sheet 包。

Overlay

45% 遮罩，点击遮罩或按 Esc 关闭，关闭时 150ms 淡出。

Content · right

右侧贴边，宽 360px、全高，border-left 1px，背景 --sh-bg-overlay。

Content · bottom

底部贴边，高度上限 85vh，顶部 14px 圆角，36×4 拖拽条仅作视觉提示。

Header

标题 18px / 600，右侧关闭图标；副标题 12px 说明已应用条件与结果数。

Body

唯一滚动区，min-height: 0 保证长内容可滚动，分组标题 12px。

Footer

固定在底部，右侧对齐「重置 / 应用筛选」；移动端按钮等宽。

state

open / closing（150ms 淡出）/ scrollable；打开时锁定背景滚动。

使用禁忌

行为约定：使用 Radix Dialog 语义（role="dialog"、aria-modal），Esc 与遮罩点击均可关闭，关闭后焦点回到触发按钮，并在打开期间把焦点限制在面板内。

  • 不要用全屏抽屉承载技能详情页，详情应走独立路由。
  • 不要多层抽屉嵌套，需要更深一层时改用 Dialog。
  • 简单确认类操作请用 Dialog，Sheet 只服务筛选、复杂表单与文件预览。
