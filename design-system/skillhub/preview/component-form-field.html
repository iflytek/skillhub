anatomy · 标签 + 控件 + 帮助

anatomy · 错误替换帮助
请输入完整的邮箱地址，例如 name@company.com。

标签变体 required / optional / with-counter

required · 必填
用于接收审核结果与治理通知。
optional · 选填
选填项，最多 80 个字。
with-counter · 字数计数
最多 120 个字 12 / 120

状态 · 六种 default / focus / filled / error / disabled / loading

default · 默认
使用小写字母、数字与连字符。
focus · 聚焦
聚焦时描边转为近黑，并附 2px 外环。
filled · 已填写
已保存，修改后需重新提交审核。
error · 错误
只能使用小写字母、数字与连字符，不能包含空格。
disabled · 禁用
审核期间不可修改命名空间。
loading · 校验中
正在检查该命名空间是否可用…

尺寸 sm 24px / md 28px

sm · 24px 控件
紧凑表格与筛选栏使用 sm 尺寸。
md · 28px 控件
表单页默认使用 md 尺寸。

布局 vertical 堆叠 / horizontal 标签在左

vertical · 两字段堆叠表单

新建命名空间

创建后可在成员管理中添加协作者。

会展示在技能卡片与搜索结果中。
帮助其他成员判断是否适用。
horizontal · 标签在左
横向布局仅用于设置项，默认仍为标签在上。

禁忌 静态预览的三条红线

  • 01不要把标签做成浮动标签，或用占位符替代标签；标签必须常驻在控件上方（12px/500）。
  • 02不要在同一个字段同时显示帮助与错误文案，错误出现时应替换帮助文本。
  • 03不要给标签上色或用图标替代必填标识；必填统一使用危险色星号，选填标注为「选填」。
