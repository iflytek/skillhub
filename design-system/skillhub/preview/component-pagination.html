Pagination 分页

pagination

28px 方块页码，当前页近黑实心。用于搜索结果与技能列表；首末页自动禁用对应方向的按钮。

  • 页码按钮 28 × 28
  • 当前页 aria-current="page"
  • 最多 7 个页码
  • 移动端仅保留上一页 / 下一页

01桌面端 · numbers

第 1–7 页，当前第 3 页。右侧标注当前页对应的 aria-current="page"。

←第 3 页aria-current="page"

02页码状态 · idle / hover / active / disabled

默认透明底；悬停使用 --sh-accent-base；当前页使用 --sh-primary-base 实心；禁用态 40% 透明度且不响应点击。

默认

透明底，文字使用 --sh-text-primary。

悬停

底色切换为 --sh-accent-base，150ms 过渡。

当前页

实心 --sh-primary-base，白字，aria-current="page"。

禁用

禁用色底与 text-disabled，cursor not-allowed。

03首末页 · prev / next 禁用

第 1 页禁用「上一页」，第 7 页禁用「下一页」；另一侧保持可点击，页码组不变。

05移动端 · 精简版

屏幕宽度不超过 640px 时隐藏页码组，只保留「上一页 / 下一页」，中间补充当前页与总页数。

06规格

尺寸与色彩来自契约，键盘焦点与禁用规则保证可访问性。

页码按钮

28 × 28px，圆角 6px，字号 13px

按钮间距

页码之间 6px，分组之间 12px

当前页

实心 --sh-primary-base，标记 aria-current="page"

悬停

背景 --sh-accent-base，过渡 150ms

键盘焦点

2px --sh-border-focus 外描边，偏移 2px

禁用态

禁用色底、text-disabled，cursor not-allowed，不可点击

页码上限为 7 个，超出后使用省略号折叠；不使用彩色页码，也不使用圆形大按钮分页。本页为静态预览，按钮不触发翻页。

所有颜色、间距、圆角与动效均来自 colors_and_type.css；本页为静态预览，不含脚本。
