Alert 提示条

发丝线 + 浅软底的单行提示，语义色只作用于图标与文字，不做整块高饱和色域。

语义色调 tone · neutral / info / success / warning / danger

发布权限由 @global 命名空间 OWNER 授予。
neutral · 权限与安全说明
待审核版本预计 1 个工作日内完成审核。
info · 待审核流程提示
合规扫描通过，未发现高危依赖与敏感凭据。
success · 合规扫描通过
该版本包含 2 个可执行脚本，请确认来源可信。
warning · 可执行脚本提醒
版本已被驳回：请根据审核意见修改后重新提交。
danger · 审核驳回原因，必须给出下一步

布局 layout · single-line / title+desc / dismissible

技能包内的脚本将以只读方式加载，不写入宿主目录。
single-line · 单行权限说明
合规扫描通过 未发现高危依赖与明文凭据，可发布至 @global 命名空间。
title+desc · 合规通过，标题 13px / 600
该技能仅对 @global 命名空间成员可见。
dismissible · 可关闭提示，右侧 24px 关闭按钮

状态 state · idle / hover / dismissed

该技能仅对 @global 命名空间成员可见。
idle · 可关闭提示默认
该技能仅对 @global 命名空间成员可见。
hover · 可关闭提示 hover 时边框转深、关闭钮变底
版本已被驳回：请根据审核意见修改后重新提交。
dismissed · 关闭后淡出并移出布局

禁止整块高饱和底色；禁止带边框阴影的浮层提示；warning 使用专用软底 `--sh-warning-weak` 与 `--sh-warning-border`。
