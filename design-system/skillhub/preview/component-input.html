Input / Textarea 输入

28px 高、6px 圆角、13px 字号、发丝边框；聚焦时只把边框转为近黑，不叠加外环。

单行输入 · 状态 idle / focus / error / disabled

idle 必填，审核员会在 3 个工作日内处理。
focus 聚焦时边框转为近黑，不出现第二层外环。
error 请至少填写 10 个字，说明具体差异。
disabled 如需补充材料，请在审核详情页上传。

多行输入 · 评价内容 default / focus / error

default 支持 Markdown0 / 500
focus 支持 Markdown48 / 500
error 评价内容不能为空，至少填写 20 个字。
