## Codebase Patterns
- New auth-provider integrations should normalize upstream provider payloads into small internal DTO/record types inside `skillhub-auth`, so application services never depend on provider-specific contracts.
- When running Maven from `server/pom.xml` with `-pl ... -am -Dtest=...`, add `-Dsurefire.failIfNoSpecifiedTests=false` so upstream modules without matching tests do not fail the build.
- Optional Redis-backed auth helpers in this codebase should choose Redis vs local fallback in a dedicated `@Configuration` bean via `ObjectProvider<RedisTemplate<...>>`, not by scattering cache-mode branches through services.
- Configuration-only behavior here is usually validated with lightweight `Binder` or `ApplicationContextRunner` tests instead of full `@SpringBootTest` contexts.
