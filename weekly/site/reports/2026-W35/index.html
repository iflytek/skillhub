统计口径

  • 统计周期本期展示为 2026-08-21—2026-08-27，Asia/Shanghai；程序过滤采用半开区间 [2026-08-21 00:00:00, 2026-08-28 00:00:00)，对应 UTC 为 [2026-08-20 16:00:00, 2026-08-27 16:00:00)。
  • 统计时点2026-08-28 16:55:22（Asia/Shanghai）；仓库库存、开放队列和年龄结构取该快照。快照之后的事件不计入本期流量。
  • Issue 与 PR 的区分GitHub Issues API 同时返回 PR；Issue 流量剔除带 pull_request 字段的条目，PR 流量使用 Pull Requests 端点独立计算。
  • Star 证据证据等级为 current-visible-arrivals：65 为 starred_at 落入本期且在 8 月 28 日查询时仍可见的记录数，不代表周期净增长。与上次认证观测（8 月 21 日 18:23，4,887）相比，本次观测（4,904）变化为 +17，仅表示两个观测点之间的库存差值。
  • PR 统计分支仅统计目标为 main 的 PR；不计入 big-main 或其他集成分支。
  • Release按 published_at 过滤，本期应用 Release 为 1、CLI Release 为 0。v0.2.17 于 8 月 21 日 18:13 发布；其余本期合入改动未发现后续 Release。
  • 交付状态用词“已发布”要求存在包含改动的 Release；“主分支待发布”只表示提交可从 main 到达。没有生产部署证据，因此不使用“已上线”。
  • Actions 成功率success / (success + failure)；跳过和取消不进入分母，但单独展示。
  • 当前存量开放 Issue/PR、年龄结构和 needs-info 是 8 月 28 日快照，不代表本期期末库存，也不参与周流量计算。
